Este curso estará inspirado en el curso de "[Curso Maestro de Python: De Cero a Programador Todoterreno](https://www.udemy.com/course/python-3-al-completo-desde-cero/)" (se puede encontrar [aquí](https://hektorprofe.github.io/python/) también), la experiencia propia, y un sin fin de páginas en Internet que esporádicamente me han ido acompañando todos estos años.

Para todas estas prácticas, usaré Python 3.14.2 y Windows 10. Por otro lado, usaré un Python "puro" sin Conda, Jupyter u otros intérpretes extra. Para programar, únicamente lo haré en Visual Studio Code, donde recomiendo instalar las extensiones oficiales de Python ([[1.1 Extensiones para Python]]). Por otro lado, para hacer alguna prueba rápida usaré la terminal.
