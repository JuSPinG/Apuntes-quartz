# Sentencia `if`

La sentencia `if` nos ayuda a dividir el flujo. Podemos imaginárnoslo como una carretera con una bifurcación. Hay que elegir si ir a la izquierda o a la derecha. En muchos casos, ambos carriles se acabarán juntando más adelante, lo único que habrá cambiado para ese entonces será lo que hayamos visto por la ventanilla y el tiempo que habremos tardado. Codifiquemos esta metáfora:

```py
izquierda = True

if izquierda == True:
	print("Vas a la izquierda. El paisaje es bonito pero vas muy lento")
	parar_el_programa_segundos(5) # Esto es un ejemplo de pseudocódigo, realmente esa función no existe
if izquierda == False:
	print("Vas a la derecha. El paisaje es feo pero tardas poco")
	parar_el_programa_segundos(1) # Pseudocódigo, por ser, sería time.sleep(1)
print("Llegaste al destino!")
```

Este programa usa fragmentos de pseudocódigo, que es una forma de programar para entendernos entre nosotros los humanos. No se puede ejecutar, por lo que voy a hacer un poco de "magia avanzada" para que así sea. Este sería el programa ejecutable:

```py
from time import sleep

izquierda = True

if izquierda == True:
	print("Vas a la izquierda. El paisaje es bonito pero vas muy lento")
	sleep(5)
if izquierda == False:
	print("Vas a la derecha. El paisaje es feo pero tardas poco")
	sleep(1)
print("Llegaste al destino!")
```

En este caso, como la variable `izquierda` es `True`, entonces vamos por el camino lento. Podemos cambiarla a `False` y comprobar que vamos por el camino lento. Ahora, pase lo que pase, se acaba imprimiendo por pantalla el "Llegaste al destino!". 

Vamos a mejorar el programa. Hay una pequeña mentirijilla introducida para hacer el programa más simple. La sentencia `if` evalúa inmediatamente después si lo que se encuentra es un [[2.1.5 Tipo booleano|Tipo booleano]], y si es así, cuál es su estado. En el caso de que este sea `True`, hace pasar el flujo por su carretera, en el caso contrario no. Si prestamos atención a lo visto en [[2.1.6 Operadores lógicos y relacionales|Operadores lógicos y relacionales]]. Sabremos que, en el caso de que `izquierda == True`, esta sentencia devuelve `True`. ¿Para qué complicarlo si ya desde un principio `izquierda` es `True`? por lo que podemos simplificar el programa:

```py
from time import sleep

izquierda = True

if izquierda:
	print("Vas a la izquierda. El paisaje es bonito pero vas muy lento")
	sleep(5)
if izquierda == False:
	print("Vas a la derecha. El paisaje es feo pero tardas poco")
	sleep(1)
print("Llegaste al destino!")
```

Lo vuelvo a repetir por su gran importancia: `if` evalúa lo que se encuentra delante, antes era `izquierda == True`, lo que devolvía `True`. Podemos hacer la prueba:

```py
izquierda = True  

print(izquierda, izquierda == True, (izquierda == True) == True)
```

Las comas hacen que las impresiones se separen con espacios, devolviendo así:

```py
True True True
```

# Sentencia `elif`

Espero que haya quedado claro, vamos a mejorar un poco más el programa:

```py
from time import sleep

izquierda = True

if izquierda:
	print("Vas a la izquierda. El paisaje es bonito pero vas muy lento")
	sleep(5)
elif not izquierda: # Introducción del `not` y sustitución del `if` por `elif`
	print("Vas a la derecha. El paisaje es feo pero tardas poco")
	sleep(1)
print("Llegaste al destino!")
```

Los cambios realizados ahora se aplican en la última sentencia de flujo. Uno de los cambios, repito, si se ha prestado atención en [[2.1.6 Operadores lógicos y relacionales#^78c65d|Operadores lógicos y relacionales]], se deduce fácilmente: el `not` cambia `True` por `False` y viceversa, por lo que `izquierda` que antes era `True`, se evalúa como `not True` lo que equivale a `False` (esto no quiere decir que se haya guardado el nuevo valor de `izquierda`).

Hay otro cambio. Se ha sustituido el `if` por el `elif`. Sin embargo, el comportamiento es aparentemente el mismo. En realidad hay un cambio, uno lógico que suele ahorrar comprobaciones innecesarias. En [[Python]], una variable [[2.1.5 Tipo booleano|Tipo booleano]] solo puede tener 2 estados (puede tener más, pero no vamos a entrar ahí), por lo que podemos asumir que si vamos a la izquierda, entonces no vamos a la derecha; y si vamos a la derecha, entonces no vamos a la izquierda. No sabemos cual, pero tenemos claro que únicamente iremos a un camino (al menos en una ejecución). `elil` nos proporciona esta lógica, pero para verlo mejor vamos a cambiar momentáneamente de ejemplo:

```py
nombre = input("¿Cuál es tu nombre?: ") # Respuestas propuestas: Cristian y Juan (en ese orden)

if nombre == "Juan": # Se ejecuta únicamente con Juan
    print("Juan, justo así se llamaba mi tío")
if nombre[-1] == 'n': # Se ejecuta con Cristian y Juan
    print("Los nombres que acaban en 'n' son los mejores")
```

Si respondemos a la pregunta con "Cristian", entonces, el programa nos dirá que "Los nombres que acaban en 'n' son los mejores". Cuando indicamos que nuestro nombre es "Juan", entonces el programa nos responderá con que "Juan, justo así se llamaba mi tío" pero también nos dirá que "Los nombres que acaban en 'n' son los mejores".

Al sustituir el último `if` por `elif`, entonces las puertas no se abren de la misma manera:

```py
nombre = input("¿Cuál es tu nombre?: ")

if nombre == "Juan": # Se ejecuta únicamente con Juan
    print("Juan, justo así se llamaba mi tío")
elif nombre[-1] == 'n': # Se ejecuta únicamente con Cristian
    print("Los nombres que acaban en 'n' son los mejores")
```

El comportamiento con "Cristian" se mantiene, pero con "Juan" cambia. Como ya se ha cumplido una condición anterior, ya no se puede volver a entrar en otra. Si hay varias condiciones de este tipo seguidas, y una de `if` se cumple, las de `elif` ya no podrán ejecutarse. `elifp` no dice: "Puedes entrar, siempre y cuando yo sea el único". Por eso tiene sentido implementarlo en nuestro programa de la carretera, porque si va a la izquierda, no queremos que vaya a la derecha.

# Sentencia `else`

`elif` está bien para nuestro ejemplo de carretera, pero a lo mejor sería más interesante aplicar un`else`. Esta sentencia nos indica que se ejecutará únicamente si ningún `if` o `elif` se han cumplido anteriormente. Es "o va a la izquierda, o pasa esto":

```py
from time import sleep

izquierda = True

if izquierda:
	print("Vas a la izquierda. El paisaje es bonito pero vas muy lento")
	sleep(5)
else:
	print("Menos mal que no has ido a la izquierda, hbía un atasco de la leche")
	sleep(1)
print("Llegaste al destino!")
```

Puede que este ejemplo no tenga mucho sentido porque estamos con estados binarios. Vamos a inventarnos otro programa, de reserva de hoteles:

```py
cafe = int(input("1) Manchado\t 2) Cortado\t 3) Entero\n¿Qué café quieres? (introduce el número): "))

if cafe == 1:
    print("Buena elección. El manchado es mi favorito")
elif cafe == 2:
    print("¡Oh venga! Ese está malísimo")
elif cafe == 3:
    print("Tú sí que sabes. Café para cafeteros")
else:
    print("Eso ni siquiera es una opción válida. Vuelve a intentarlo")
```
