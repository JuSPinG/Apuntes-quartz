# Introducción al texto

El texto, o la cadena (en Python usaremos `string` para referirnos a este tipo), es un tipo de dato extremadamente versátil:

```py
nombre = "Juan"
numero = '6'
```

Podemos usar comillas simples o comillas dobles indistintamente, siempre y cuando sabiendo que si iniciamos una cadena con comillas dobles, únicamente podemos cerrarla con comillas dobles. Varios casos de ejemplo:

```py
texto = "Ejemplo de comilla simple: '"
texto = 'Ejemplo de comilla doble"'
texto = "Ejemplo de comilla doble \" siendo encerrada por un texto de comillas sobles"
```

El carácter "\\" es especial pues permite interacciones únicas en el texto. En este caso, permite hacer que la comilla doble «escape» y se entienda como tal dentro de un contexto de comillas dobles. Por poner otro ejemplo:

```py
texto = "Este es un texto \nMultilínea"
```

El "\n" se interpreta como si le diésemos al enter. Si hacemos un `print(texto)`, obtendremos:

```py
Este es un texto
Multilínea
```

En otro ejemplo, así escribiríamos una variable con una ruta:

```py
ruta = "C:\\Clase\\Python"
```

Para que el programa realmente lea: `C:\Clase\Python`. También podemos indicar que el texto de la cadena es «crudo» (_raw_):

```py
ruta = r"C:\Clase\Python"
```

La última peculiaridad de las cadenas en Python es que podemos hace una «cadena multilínea»:

```py
texto_largo = """

Lorem ipsum dolor sit amet, consectetur adipiscing elit,
sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

"""

print(texto_largo)
```

Y se nos imprimirá justo esto:

```py

Lorem ipsum dolor sit amet, consectetur adipiscing elit,
sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.

```

# Operaciones con textos

Sí, de la misma forma que podemos sumar números en Python, podemos sumar también textos:

```py
nombre = "Benito"
apellido = "La Osa"
nombre_completo = nombre + apellido
```

Desafortunadamente, no se incluye un espacio de forma predeterminada (quedando "BenitoLa Osa"), pero podemos agregarlo:

```py
nombre = "Benito"
apellido = "La Osa"
nombre_completo = nombre + " " + apellido

print(nombre_completo)
```

Y ahora, esto sí, devuelve: "Benito La Osa". También podemos multiplicar textos:

```py
saludo = "Hola un millón de veces\n"
print(saludo*1000000)
```

En este caso, se imprime la cadena de texto un millón de veces, pues se ha multiplicado por esta cantidad.
