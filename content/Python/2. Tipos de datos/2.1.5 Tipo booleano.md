El tipo booleano, o tipo lógico es sencillo de entender. A diferencia del tipo numérico o el tipo texto, que comprenden millones de estados y posibilidades, el tipo booleano es más fundamental: únicamente sí o no.

```py
soltero = True
cumpleannos = False
```

Usamos `True` o `False` para referirnos si algo es verdadero o falso. A priori, no parece un tipo de dato que se use a menudo, pero cuando hagamos programas más complejos será típico su uso, sobre todo implícito.

Por otro lado, podemos convertir tipos de dato. En este caso, podemos transformar ese tipo de dato a número:

```py
print(int(True))  # Esto devuelve 1
print(int(False)) # Esto devuelve 0
```

# Comportamiento aritmético

Este tipo posee cierto comportamiento aritmético que nos permite hacer operaciones con él. No suele ser muy común verlo, al menos en mi experiencia personal, pero es interesante conocerlo, sobre todo en sistemas donde el rendimiento es crítico (jamás será el caso de Python).

No hay siquiera que hacer un _cast_ (que es la transformación de un tipo de dato a otro); podemos, directamente, multiplicar o sumar un booleano con otros datos:

| Expresión        | Resultado | Explicación                                                |
| ---------------- | --------- | ---------------------------------------------------------- |
| `True + True`    | 2         | Esto equivale a encendido más encendido. Es decir, $1 + 1$ |
| `False + True`   | 1         | `False` equivale a 0                                       |
| `False + False`  | 0         | Se deduce de la explicación de antes                       |
| `True + "Hola"`  | Error     | No se puede sumar un booleano/entero con un `string`       |
| `False + "Hola"` | Error     | Lo mismo que lo anterior                                   |
| `True + 10`      | 11        | `1 + 10 = 11`                                              |
| `False + 10`     | 10        | `0 + 10 = 10`                                              |
| `True * True`    | 1         | Equivale a $1 \times 1$                                    |
| `True * False`   | 0         | Cualquier cosa multiplicada por 0 (`False`) es 0           |
| `False * 10`     | 0         | Equivale a $0 \times 10$                                   |
| `True / 2`       | 0.5       | Equivale a $1 / 2$                                         |
| `False / 5`      | 0.0       | Equivale a $0 / 5$                                         |
| `10 / False`     | Error     | No se puede dividir por cero (`ZeroDivisionError`)         |
| `True * "Hola"`  | "Hola"    | La identidad                                               |
| `False * "Hola"` | ""        | Se vacía la cadena                                         |

# Crear condiciones

Se pueden transformar los datos a booleano de otra forma. Podemos preguntarnos, por ejemplo, si $1+1=2$.

```py
print(1+1 == 2) # Esto devuelve True
```
