Una variable es un dato que guaramos en la RAM para reutilizarlo más tarde. Por ejemplo:

```py
>>> x = 10
>>> x
10
```

Si accedemos al valor de `x`, obtenemos un "10", síntoma de que se ha guardado. Podemos modificar el valor de las variables (de ahí su nombre):

```py
>>> y = 20
>>> y = 10
>>> y
10
```

Pero también podemos someterlas a operaciones:

```py
>>> x = 10*2
>>> y = x/4
>>> z = y*x
>>> z
100
```

Hay más trucos con las variables, por ejemplo, podemos operar mientras hacemos una asignación:

```py
>>> x = 10
>>> x -= 1
>>> x
9
```

Y también podemos intercambiar valores de 2 variables:

```py
>>> n_1 = 5
>>> n_2 = 10
>>> n_1, n_2 = n_2, n_1
>>> n_1, n_2
(10, 5)
```

# Reglas en la declaración de variables

Las variables tienen pocas normas a la hora de declararlas, estas son:

1. La variable no puede comenzar con un número.
2. La variable no puede contener espacios.
3. La variable no puede tener carácteres especiales.
4. Se recomienda usar "\_" para los espacios.
5. Se recomienda usar únicamente minúsculas.

Por último, es importante recalcar que las operaciones con variables siguen un orden:

```py
>>> nota_1 = 10
>>> nota_2 = 5
>>> nota_media = (nota_1 + nota_2)/2
>>> nota_media
7.5
```

Si no usamos paréntesis, queda "10" en vez de "7.5".
