Los tipos de datos simples son aquellos que no se componen de otros para existir (esta afirmación es parcialmente falsa, pero bastante útil). En consecuencia, podemos definir a los [[2.2 Tipos de datos compuestos|Tipos de datos compuestos]] como un conjunto de datos simples. Puede parecer un poco lioso, pero cuando entremos en materia será más fácil de entender.
