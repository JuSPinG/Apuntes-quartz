La función `input()` nos permite recoger un dato por la termial. Veamos un ejemplo:

```py
# Input
print("¿Cuál es tu nombre?")
print("Encantado de conocerte " + input())
# Output
¿Cuál es tu nombre?: 
Juan # Del input()
Encantado de conocerte Juan
```

Este programa nos pregunta por un nombre, y se detiene hasta que escribamos algo (preferiblemente un nombre) y le demos al enter. Este programa es considerablemente ortopédico y es considerado una práctica un tanto extraña de la programación. Se vuelve más interesante guardar el resultado en una variable.

```py
# Input
print("Introduce tu edad")
edad = input()
print("Tu edad es de " + edad)
# Output
Introduce tu edad
40 # Del input()
Tu edad es de 40
```

Vamos a mejorar un poco este programa. La función `input()` puede recibir un argumento, siendo este el texto que se va a imprimir en la misma línea:

```py
# Input
apellido = input("Introduce tu apellido: ")
print("Tu apellido es " + apellido)
# Output
Introduce tu apellido: Bravo # Del input()
Tu apellido es Bravo
```

Podemos complicar un poco más el programa:

```py
datos = []

datos.append(input("Nombre: ")) # Yo pondré: Juan
datos.append(input("Apellido: ")) # Yo pondré: Diego
datos.append(int(input("Edad: "))) # Yo pondré: 30

print("El usuario " + datos[0], datos[1] + " tiene una edad de " + str(datos[2]) + ". Su próxima edad será " + str(datos[2] + 1))
```

Por lo que el resultado es:

```py
El usuario Juan Diego tiene una edad de 30. Su próxima edad será 31
```

Vemos que el número introducido se suma correctamente. Esto se debe a que el programa, internamente, interpreta que la 3ª posición de la lista `datos` es un número, y no un texto como el resto de campos. Esta ventaja se especifica escribiendo un `int()` delante del dato que queramos transformar. Puede ser problemático porque si el usuario introduce algo que no se pueda convertir a número, como por ejemplo otro nombre, el programa se cerrará por un error:

```py
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: invalid literal for int() with base 10: 'Juan'
```

No podemos convertir `Juan` a número, evidentemente.
