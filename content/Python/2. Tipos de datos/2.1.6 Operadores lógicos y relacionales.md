Los operadores lógicos y relacionales buscan encontrar una "verdad" detrás de los datos. Contamos con los siguientes:

| Signo | Nombre            | Ejemplo                                                                                           |
| ----- | ----------------- | ------------------------------------------------------------------------------------------------- |
| `==`  | Igual que         | `a == b`                                                                                          |
| `!=`  | Distinto de       | `a != b`                                                                                          |
| `>`   | Mayor que         | `a > b`                                                                                           |
| `<`   | Menor que         | `a < b`                                                                                           |
| `>=`  | Mayor o igual que | `a >= b`                                                                                          |
| `<=`  | Menos o igual que | `a <= b`                                                                                          |
| `and` | Y                 | `a == b and b == c`. La lectura sería: `a` es igual a `b` y `b` es igual a `c`                    |
| `or`  | O                 | `a == b or a != b`. Esto es una tautología, se cumple siempre que `a` es distinto o igual que `b` |
| `not` | No                | `not a`                                                                                           |

Con las operaciones relacionales (las primeras 6) relacionamos mediante booleanos las variables, y con las operaciones lógicas las concatenamos y evaluamos si al menos existe un dato `True` a ambos lados, a los 2, o debemos sustituir un valor por otro. Esta es su tabla de verdad:


| Expresión         | Resultado |
| ----------------- | --------- |
| `True or True`    | `True`    |
| `True and True`   | `True`    |
| `True or False`   | `True`    |
| `True and False`  | `False`   |
| `False or False`  | `False`   |
| `False and False` | `False`   |


El ejemplo de `not` puede ser un poco confuso, pero es extremadamente útil. Veamos un ejemplo:

```py
print(not input("Introduce tu nombre: "))
```

Ese fragmento, que a priori solo nos pide el nombre, nos devuelve `True` o `False` en función de si la variable contiene algo o no. Desglosémoslo:

```py
nombre = ""
print(not nombre) # Esto devuelve "True", porque la variable está vacía

nombre = "Juan"
print(not nombre) # Esto devuelve "False", porque la variable ya contiene algo
```

Por lo que si el resultado al `input` es la cadena vacía porque no ha introducido su nombre, entonces, el resultado será `True`. Luego volveremos a esta función por su utilidad.

Este comportamiento de la variable vacía también nos puede servir con otros tipos de datos, como con la cadena:

```py
lista = []
print(not lista) # Esto devuelve "True". No hay lista

lista.append(1)
print(not lista) # Esto devuelve "False". Sí hay cosas en la lista
```

Aunque esta función también podría haberse implementado de la siguiente manera:

```py
print(not bool(len(lista)))
```

Pensemos en la lógica que hay detrás:

1. Hay una lista.
2. Se obtiene la longitud de la lista, que es desde luego un número natural (con 0 incluido).
3. Se pasa a booleano, por lo que si es un cero (apagado), se transforma en `False`. En el caso contrario, se transforma a `True`.
4. Como hay un `not` delante, se transforma el signo. De `False` a `True` y viceversa.
5. Imprimimos el resultado.
