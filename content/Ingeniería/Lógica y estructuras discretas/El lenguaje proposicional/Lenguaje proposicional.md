# El lenguaje proposicional

El estudio de Lógica de Proposiciones (a este nivel introductorio) se presenta en tres bloques:

1. El lenguaje proposicional
2. Cuestiones semánticas
3. Cálculos e inferencia

## Sobre el lenguaje proposicional

El lenguaje facilitará expresiones como $(p\to (q\lor r))$ sobre las que representar enunciados como *"Si llueve entonces voy al cine o voy al gimnasio"* o *"Si se enciende este piloto entonces pulso el botón o desenchufo"*.

Estas facilidades de representación (que serán más expresivas en Lógica de Predicados) permiten formalizar comportamientos de sistemas o razonamientos y responder a preguntas sobre estas situaciones cotidianas con ayuda de cálculos definidos en este sistema lógico.
