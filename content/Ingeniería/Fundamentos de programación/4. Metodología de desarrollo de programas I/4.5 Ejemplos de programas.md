# 4.5.1 Ejemplo: Imprimir la figura de un árbol de navidad

Enlace: [[Fundamentos de programación.pdf#page=101&selection=78,0,96,7|Fundamentos de programación, página 101]].

Se quiere imprimir la siguiente figura:

```
    *
   ***
  *****
   ***
  *****
 *******
  *****
 *******
*********
    *
    *
    *
  *****
```

^5914f9

Esto se podría estructurar de la siguiente forma:

Imprimir árbol →
- Imprimir copa.
- Imprimir tronco.
- Imprimir base.
Imprimir copa →
- Imprimir primeras ramas.
- Imprimir segundas ramas.
- Imprimir terceras ramas.

Y así se escribiría el programa:

```c
/***************************************************************
* Programa: Árbol de navidad.
*
* Autor: Marcos Ndah.
* 
* Descripción:
*     Este programa imprime de forma esquemática la silueta
*     de una sillausando caracteres normales de la impresora.
***************************************************************

/*==================================
    DIRECTIVA DE COMPILACIÓN
==================================*/
#include<stdio.h>

/*==================================
    DIRECTIVA PRINCIPAL
==================================*/

int main() {
  /*-- Imprimir copa --*/ {
    /* Imprimir primeras ramas --*/ {
      printf("    *\n");
      printf("   ***\n");
      printf("  *****\n");
    }
    /* Imprimir segundas ramas --*/ {
      printf("   ***\n");
      printf("  *****\n");
      printf(" *******\n");
    }
    /* Imprimir terceras ramas --*/ {
      printf("   ****\n");
      printf("  *******\n");
      printf(" *********\n");
    }
  }
  /*-- Imprimir tronco --*/ {
    printf("    *\n");
    printf("    *\n");
    printf("    *\n");
  }
  /*-- Imprimir base --*/ {
    printf("  *****");
  }
}
```

# 4.5.3 Ejemplo: Calcular los días entre dos fechas

Enlace: [[Fundamentos de programación.pdf#page=104&selection=421,0,443,6|Fundamentos de programación, página 104]].

Calcular la diferencia de fechas →
- Leer las flechas.
- Calcular la diferencia.
- Imprimir el resultado.
Calcular la diferencia →
- Calcular los días desde principio de año.
- Calcular la diferencia total de días.

```c
/***************************************************************
* Programa: DiferenciasEnDias
*
* Autor: Marcos Ndah.
* 
* Descripción:
*     Este programa calcula los días entre dos fechas,
*     de forma aproximada, usando meses de 30 días y años
*    de 365 días.     
***************************************************************/

/*==================================
    DIRECTIVA DE COMPILACIÓN
==================================*/
#include<stdio.h>

/*==================================
    DIRECTIVA PRINCIPAL
==================================*/

int main() {
  int dia1, mes1, anno1;      /* Primera fecha */
  int dia2, mes2, anno2;      /* Segunda fecha */
  int diasFecha1, diasFecha2; /* Días desde inicio del año */
  int diferencia;             /* Diferencia en días */

  /*-- Leer las fechas --*/ {
    printf("Primera fecha? Formato dd, mm, aaaa: ");
    scanf("%d, %d, %d", &dia1, &mes1, &anno1);
    printf("Segunda fecha? Formato dd, mm, aaaa: ");
    scanf("%d, %d, %d", &dia2, &mes2, &anno2);
  }
  /*-- Calcular la diferencia --*/ {
    diasFecha1 = anno1*365 + mes1*30 + dia1;
    diasFecha2 = anno2*365 + mes2*30 + dia2;

    diferencia = diasFecha2 - diasFecha1;
  }
  /*-- Imprimir la diferencia --*/ {
    printf("La diferencia de dias es de: %d", diferencia);
  }
}
```
