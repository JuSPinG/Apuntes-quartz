# 5.4.1 Ejemplo: Ordenar 3 datos

Enlace: [[Fundamentos de programación.pdf#page=122&selection=183,0,193,0|Fundamentos de programación, página 122]].

## Mi propuesta

```c
/****************************************************************
* Programa: Ordenar 3 datos.
*
* Descripción:
*   Este programa lee 3 números introducidos por el usuario
*   y posteriormente los ordena, la viarable 1 adquiere el
*   valor más pequeño y la viarable 3 el mayor
****************************************************************/

#include<stdio.h>

int main() {

  /*-- Declaración de variables --*/
  int num1, num2, num3;

  /*-- Pedir y recivir los números --*/
  printf("Introduce 3 numeros separados por espacios: ");
  scanf("%d %d %d", &num1, &num2, &num3);

  /*-- Comparaciones --*/
  if (num3 > num2) {
    num3 = num3 + num2; /* Se hace un cambio de variable, aunque un poco extraño, eficiente porque no requiere de otra variable */
    num2 = num3 - num2;
    num3 = num3 - num2;
  }

  if (num2 > num1) {
    num2 = num2 + num1; /* Se repite dicho procedimiento para hacer el cambio de variable */
    num1 = num2 - num1;
    num2 = num2 - num1;

    if (num3 > num2) {
      num3 = num3 + num2; /* Se vuelve a repetir dicho procedimiento */
      num2 = num3 - num2;
      num3 = num3 - num2;
    }
  }


  printf("Tras los calculos, he ordenado los numeros de forma ascendente:\n  - Num1: %d\n  - Num2: %d\n  - Num3: %d", num1, num2, num3);
}

```

## La propuesta

```c
int main() {
  int valUno, valDos, valTres, auxiliar;

  /*-- Leer los datos --*/
  printf("¿Datos? ");
  scanf("%d %d %d", &valUno, &valDos, &valTres);

  /*-- Primer Paso: Ordenar los dos primeros datos --*/
  if (valUno > valDos) {
      auxiliar = valUno;
      valUno = valDos;
      valDos = auxiliar;
  }

  /*-- Segundo Paso: Situar el tercer dato --*/
  if (valTres < valUno) {
      auxiliar = valTres;
      valTres = valDos;
      valDos = valUno;
      valUno = auxiliar;
  } else if (valTres < valDos) {
      auxiliar = valDos;
      valDos = valTres;
      valTres = auxiliar;
  }

  /*-- Tercer Paso: Escribir el resultado --*/
  printf("Datos Ordenados = %d %d %d\n", valUno, valDos, valTres);
}
```

# 5.4.2 Ejemplo: Escribir un triángulo de dígitos

Enlace: [[Fundamentos de programación.pdf#page=124&selection=8,0,20,7|Fundamentos de programación, página 124]].

![[Ejemplo escribir un triángulo de dígitos.png]]

## Mi propuesta

```c
/*************************************************************
* Programa: Escribir una pirámide de números.
*
* Descripción:
*   Le pide al usuario que ingrese un dígito, a partir
*   de ahí, se construye una pirámide donde las esquinas
*   son un dígito 1 que va incrementando en función de
*   lo céntrico que se encuentre el dígito del eje Y = 0
*************************************************************/

#include<stdio.h>

int main() {

  int digit = 0;

  /*-- Así se evita que el usuario introduzca números muy grandes o muy pequeños, solo se requiere de un dígito positivo --*/
  while ((digit <= 0) || (digit > 9)) {

    printf("Introduce un digito positivo mayor que 0: ");
    scanf("%d", &digit);
  }

  /*-- Primer búcle, es un bucle que aumenta debido a que cada vez el rango de números imrpimibles aumenta --*/
  for (int i = 1; i <= digit; i++) {

    /*-- Bucle para el espaciado, así, queda una pirámide isoscélica --*/
    for (int e = digit; e >= i; e--) {
        printf(" ");
    }

    /*-- Aquí empieza la primera parte de la línea, que imprime un número que va aumentando --*/
    for (int e = 1; e <= i; e++) {
      printf("%d", e);
    }

    /*-- Aquí acaba la línea, su segunda parte imprime un número que va disminuyendo --*/
    for (int e = i-1; e >= 1; e--) {
      printf("%d", e);
    }

    printf("\n"); /* Un enter para montar la pirámide */
  }
}
```

## La propuesta

```c
#include <stdio.h>

int main() {
  const int centro = 35; /* Posición del eje del triángulo */
  const int inicial = 1; /* Dígito inicial: superior y laterales */
  int nivel;

  /*-- Leer los datos --*/
  printf("Altura del triángulo? ");
  scanf("%d", &nivel);

  /*-- Una iteración por cada línea del triángulo --*/
  for (int altura = inicial; altura <= nivel; altura++) {

      /*-- Paso 1º: Situar primer número de cada línea --*/
      for (int indice = 1; indice <= centro - altura; indice++) {
        printf(" ");
      }
      printf("%d", inicial);

      /*-- Paso 2º: Primera mitad de la línea del triángulo
          Escribir números consecutivos hasta altura --*/
      for (int indice = inicial + 1; indice <= altura; indice++) {
        printf("%d", indice);
      }

      /*-- Paso 3º: Segunda mitad de la línea del triángulo.
          Escribir números decrecientes hasta Inicial --*/
      for (int indice = altura - 1; indice >= inicial; indice--) {
        printf("%d", indice);
      }

      /*-- Paso 4º: Saltar a una nueva línea --*/
      printf("\n");
  }
}
```
# 5.4.3 Ejemplo: Elaboración de tickets y resúmenes

Enlace: [[Fundamentos de programación.pdf#page=126&selection=8,0,35,2|Fundamentos de programación, página 126]].

```c
#include <stdio.h>

int main() {
  const float PrecioBase = 6.0; /* Precio de la butaca */
  int butacas = 0;             /* Número de butacas vendidas */
  int edad = 0;                /* Edad del cliente */
  float totalEuros = 0.0;      /* Total de euros recaudados */
  float precio = 0.0;          /* Precio de cada butaca */
  char opcion = ' ';           /* Opción del programa */
  char tecla = ' ';            /* Tecla S/N */

  /*-- Bucle hasta opción F de fin --*/
  while (opcion != 'F') {
    printf("Opción (Ticket, Resumen o Fin) ? ");
    opcion = ' ';
    while (opcion != 'T' && opcion != 'R' && opcion != 'F') {
      scanf(" %c", &opcion);
    }

    /***********************************
    * Elaboración del Ticket
    ***********************************/
    if (opcion == 'T') {
      tecla = 'S';
      while (tecla == 'S') {
        printf("Edad? ");
        scanf("%d", &edad);
        butacas++;
        printf("\n--------- TICKET DE ENTRADA ---------\n");
        if (edad < 6) {
          printf("  * niño, gratis *\n");
          precio = 0.0;
        } else if (edad < 18) { /* joven, 50% */
          printf("  * joven, 50% *\n");
          precio = PrecioBase / 2.0;
        } else if (edad < 65) { /* adulto, tarifa completa */
          printf("  * adulto *\n");
          precio = PrecioBase;
        } else { /* jubilado, 25% */
          printf("  * jubilado, 25% *\n");
          precio = PrecioBase * 4.0 / 5.0;
        }
        totalEuros += precio;
        printf("  * Precio: %.2f€\n", precio);
        printf("-------------------------------------\n\n");
        printf("Otro Ticket (S/N)? ");
        tecla = ' ';
        while (tecla != 'S' && tecla != 'N') {
          scanf(" %c", &tecla);
        }
      }
    }

    /***********************************
    * Elaboración del Resumen de la recaudación
    ***********************************/
    if (opcion == 'R') {
      printf("\n--------- RESUMEN DE VENTAS ---------\n");
      printf("%d Butacas\n", butacas);
      printf("Total Recaudado = %.2f€\n\n", totalEuros);
    }
  }
}

```
