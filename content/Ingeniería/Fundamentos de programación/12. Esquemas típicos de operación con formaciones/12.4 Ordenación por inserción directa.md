Hay varios algoritmos que ordenan un vector, aunque eso no se explica en esta materia. El método de ordenación por inserción directa es sencillo y fácil de entender.

Supongamos el siguiente vector:

```python
v = [21, 5, 3, 12, 65, 9, 36, 7, 2, 45]
```

`v[0]` no requiere de ordenación por falta de comparación, mas `v[1]` debería de ocupar la posición 0, por lo que se intercambia con este, luego, se incrementa una posición.

![[Ejemplo ordenación por inserción directa.png]]

```c
typedef ... T_Elemento ...;

void OrdenarVector(T_Elemento v[], int N) {
  int j;
  T_Elemento valor;

  /*
  INVARIANTE: v[0, ..., i - 1] está ordenado
  INVARIANTE: \forall k \ni (1, ..., i - 1); v[k] >= v[k - 1]
  */
  for (int i = 1; i < N; i++) {
    valor = v[i];
    j = i;
    while (j > 0 && valor < v[j - 1]) {
      v[j] = v[j - i];
      j--;
    }
    v[j] = valor;
  }
  /*
  POST: v'[0, ..., N - 1] está ordenado y contiene los valores v[0, ..., N - 1]
  */
}
```
