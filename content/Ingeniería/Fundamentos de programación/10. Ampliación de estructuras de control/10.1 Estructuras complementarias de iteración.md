# 10.1.1 Repetición: Sentencia `do`

Enlace: 

Esta sentencia obliga cumplir la primera iteración del bucle, y más tarde comprueba la sentencia de ejecución para ver si tiene que reiterarse.

```c
do {
  Acción;
} while (Condición);
```
# 10.1.2 Sentencia `continue`

Enlace: 

Esta sentencia hace que se pase a la siguiente iteración del bucle, y se finaliza la actual. Un ejemplo práctico:

```c
for (int i = 0; i < N; i++) {
  ...
  if (vectorCoeficientes[i] == 0) {
    continue;
  }
  ...
  calculo = calculo / vectorCoeficientes[i];
}
```
