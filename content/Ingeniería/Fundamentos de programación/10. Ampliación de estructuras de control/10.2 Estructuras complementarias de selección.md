# 10.2.1 Sentencia `switch`

Enlace: 

Para agilizar los `if`s interminables y recorrerse todos los casos de una manera más sencilla:

```c
switch (expresión) {
  case valor1:
    acción1;
    break;
  case valor2:
  case valor3:
  case valor4:
	acción234; /* Si sucede el caso 2, 3, o 4 */
	break;
  case valor5:
  case valor6:
  ...
  default: /* Si no se da ninguno de los anteriores, si no está el default y no se cumple alguna de las anteriores, escapa por error */
    acciónZ;
}
```
