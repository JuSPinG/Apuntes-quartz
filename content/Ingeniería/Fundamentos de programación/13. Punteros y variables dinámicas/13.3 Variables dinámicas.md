# 13.3.1 Punteros

Enlace: [[Fundamentos de programación.pdf#page=362&selection=290,0,292,8|Fundamentos de programación, página 362]].

Un puntero es una referencia de otra variable. El puntero no es de ningún tipo, es, sencillamente, un elemento que señala a otro.

![[Ejemplo puntero.png]]

Así se crea un puntero:

```c
typedef TipoVariable* TipoPuntero;
```

Y ahora un ejemplo más práctico:

```c
typedef int* T_Entero;
T_Entero pe;

*pe = 33;
printf("%d", *pe);
```

Si el puntero no señala a una variable dinámica, entonces, su valor puede ser impredecible. Para manejar esto, se usa la librería `stdlib.h`:

```c
if (pe != NULL) {
  *pe = 33;
  printf("%d", *pe);
}
```
# 13.3.2 Uso de variables dinámicas

Enlace: [[Fundamentos de programación.pdf#page=364&selection=63,0,83,4|Fundamentos de programación, página 364]].

Las variables dinámicas están hechas para desaparecer rápidamente (es necesario especificarlo implícitamente, se hace con `delete puntero;`), no tienen un espacio en la memoria reservado, si no que se crean a partir de ser señaladas por punteros.

```c
typedef T_Variable* T_Puntero;
T_Puntero puntero;

puntero = new T_Variable;
```

Una variable dinámica puede estar referenciada por más de un puntero. Esto ocurre cuando se copia un puntero en otro:

```c
typedef int* T_Entero;
T_Entero p1, p2;

p1 = new int;
p2 = p1;
```
