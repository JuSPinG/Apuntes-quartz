Un computador requiere de estos 3 componentes: CPU, memoria y módulo E/S, que se comunican entre sí mediante el bus.

![[Estructura de las conexiones con los componentes de un ordenador.png]]

1. La memoria es un módulo que guarda $N$ palabras de igual longitud, y cada palabra, tiene asignada una dirección numérica $(0, 1, ..., N-1)$. Las palabras se pueden leer o escribir en memoria.
2. El módulo E/S es funcionalmente similar a la memoria. También se puede leer o escribir, también puede controlar más de un dispositivo externo, esto lo hace mediante puertos. Cada a cada puerto es asignada una dirección $(0, 1, ..., N)$. También, el módulo E/S puede enviar señales de interrupción.
3. La CPU lee instrucciones y datos, que se escriben después de procesarlos, y utiliza señales de control para dirigir la operación global del sistema. Puede recibir señales de interrupción.

Las estructuras de interconexión soportan los siguientes tipos de transferencia:

- Memoria a CPU.
- CPU a memoria.
- E/S a CPU.
- CPU a E/S
- E/S a memoria (DMA).
- Memoria a E/S (DMA).

A lo largo de los años, se han planteado diferentes estructuras de interconexión:

- E/S a través de la CPU.
	- Fue adoptada inicialmente por los primeros computadores. Es la más simple, la CPU está entre el E/S y la memoria, por lo que los datos pasan siempre por esta, lo que obliga a la CPU dejar de calcular montanamente.
	- ![[E-S a través de la CPU.png]]
- E/S a través de la memoria.
	- Permite una conexión más fluida entre las partes, pues no se requiere de que la CPU pare cada cierto tiempo para intercambiar datos. Cuando la CPU necesita algo del E/S, coloca una petición en memoria, y el módulo E/S, que lee periódicamente esa dirección, se percata del mensaje. El problema de esta arquitectura es que es difícilmente ampliable.
	- ![[E-S a través de memoria.png]]
- E/S mediante un conmutador central.
	- Aquí existe un mecanismo centralizado que maneja todos los componentes. Este mecanismo maneja el acceso de la memoria al CPU como al E/S. Este sistema es perfecto, si no se tiene en cuenta la complejidad del sistema y su costo en _hardware_.
	- ![[E-S mediante un conmutador central.png]]
- Bus de E/S.
	- Conecta los módulos E/S con la memoria mediante unos "microprocesadores de E/S". Debido a su flexibilidad y simplicidad, se ha convertido en todo un estándar para microcomputadores y microcomputadores.
	- ![[Bus E-S.png]]
