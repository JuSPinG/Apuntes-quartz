La [[Fórmula de la probabilidad condicionada]] se puede aplicar de igual forma en el mundo de las distribuciones discretas.

$$P(X=x\mid Y=y)=\frac{P(X=x, Y=y)}{P(Y=y)}$$
$$P(X=x, Y=y)=P(X=y)\cdot P(X=x\mid Y=y)$$

# Ejemplo

Dada la tabla:

|        | $Y=1$ | $Y=2$ | $Y=3$ |     |
| :----: | :---: | :---: | :---: | :-: |
| $X=-1$ |  0,1  |  0,2  |  0,1  | 0,4 |
| $X=0$  |   0   |  0,1  |  0,2  | 0,3 |
| $X=1$  |  0,1  |  0,2  |   0   | 0,3 |
|        |  0,2  |  0,5  |  0,3  |     |
Entonces, para calcular $X\mid Y=2$ es necesario calcular antes $P(X=-1\mid Y=2), P(X=0\mid Y=2), P(X=1\mid Y=2)=0,5$, luego, hay que dividir los valores condicionados por el resultado obtenido, así se obtiene la probabilidad de la fila/columna en vez de la matriz entera:

$$P(X=-1\mid Y=2), P(X=0\mid Y=2), P(X=1\mid Y=2)=0,5\rightarrow \frac{P(X=-1\mid Y=2)}{0,5}, \frac{P(X=0\mid Y=2)}{0,5}, \frac{P(X=1\mid Y=2)}{0,5}$$

|        | $Y=2$ |
| ------ | :---: |
| $X=-1$ |  0,4  |
| $X=0$  |  0,2  |
| $X=1$  |  0,4  |
# Ejemplo

Supongamos la variable aleatoria $X$ con distribución binomial de parámetros $n=2$ y $p=Y$, donde $Y$ es otra variable aleatoria con distribución:

$$P(Y=0,25)=P(Y=0,5)=P(0,75)=\frac{1}{3}$$

Entonces, la distribución conjunta con $X$ es:

$$P(X=1, Y=0,25)=P(Y=0,25)\cdot P(X=1\mid Y=0,25)=\frac{1}{3}\binom{2}{1}0,25\cdot 0,75$$

Por otro lado, también podemos hallar la probabilidad de $X=1$ de la siguiente forma:

$$P(X=1)=\sum_{y=0,25,\ 0,5,\ 0,75}P(Y=y)\cdot P(X=1\mid Y=y)=\frac{5}{12}$$

Esta distribución puede ser medida bajo la esperanza matemática:

$$E\{X\mid Y=j\}=\sum_{i\in X(\Omega)}iP(X=i\mid Y=j)$$
