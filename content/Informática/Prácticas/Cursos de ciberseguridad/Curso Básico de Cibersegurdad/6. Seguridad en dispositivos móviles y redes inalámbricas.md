# Dispositivos móviles

La popularidad de los dispositivos móviles conlleva a mayores riesgos en la seguridad de los mismos. Por ello, se recomienda:

1. Bloquear el móvil con una contraseña robusta.
2. Eliminar las previsualizaciones de los mensajes.
3. Deshabilitar las conexiones inalámbricas cuando no sean necesarias.
4. Mantener actualizado el _software_ y configurar su seguridad.
5. Controlar el acceso con permisos de las aplicaciones.
6. Ignorar y borrar mensajes de desconocidos.

# Seguridad en redes inalámbricas

Para maximizar la seguridad con el WiFi, se recomienda:

1. Cambiar la contraseña de acceso por defecto.
2. Modificar el SSID a otro que no sea por defecto.
3. Ocultar el SSID para mantenerlo alejado del ojo público.
4. Activar el filtrado de direcciones MAC, solo se podrán conectar los que se permitan.
5. Configurar WPA2-AES en el modo de confidencialidad de datos, así se obtiene una autenticación robusta.
6. Limitar la cobertura WLAN, y usar antenas multidireccionales.
7. Desconectar la red cuando no se utilice (aunque puede que solo cuando no se use por un largo rato).
8. Desactivar el UPnP (_Universal Plug and Play_) para evitar brechas de seguridad.
9. Actualizar el _firmware_ del _router_ periódicamente.
10. Usar direcciones IP estáticas o limitar el número de direcciones reservadas (DHCP).
11. Activar el cortafuegos para que solo los usuarios autorizados tengan acceso a la red.
12. Activar la opción de _login_ y monitorear sus accesos.
13. Cambiar el DNS por defecto que traer el _router_ para aumentar la privacidad (como por ejemplo DNSCrypt).
