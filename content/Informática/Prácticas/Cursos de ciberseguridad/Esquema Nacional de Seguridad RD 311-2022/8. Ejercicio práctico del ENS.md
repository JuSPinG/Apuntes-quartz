# Valoración de un servicio

## Disponibilidad

|                                   | Alto              | Medio           | Bajo                   |
| --------------------------------- | ----------------- | --------------- | ---------------------- |
| Disposición leal o administrativa | Sí                | Sí              | Sí                     |
| La detención del servicio causa   | Daño grave        | Daño importante | Algún perjuicio        |
| Incumplimiento de la norma        | De carácter grave | Importante      | Apreciable             |
| Alteración del orden público      | Severa            | Apreciable      | Protestas individuales |
| ¿RTO? (_Recovery Time Objetive_)  | < 4h              | 4h < RTO < 24h  | 1d < RTO < 5d          |

RTO es el tiempo que puede estar un servicio sin funcionamiento antes de que aumente aún más la gravedad del asunto.
