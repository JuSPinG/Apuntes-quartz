De momento, solo hemos visto por encima la sentencia `if`, y nos hemos encontrado con una de sus peculiaridades. ¿Dónde empieza y dónde acaba la sentencia? Esto se hace mediante subsecciones, que, en [[Python]], se llevan a cabo gracias a la identación. En muchos lenguajes de programación, este comportamiento se lleva a cabo mediante llaves. Pongamos un ejemplo:

En JavaScript:
```js
if (edad >= 18) {
	console.log("Eres mayor de edad")
}
else {
	console.log("Eres menor de edad")
}
```

Como el rango del `if` y el `else` quedan delimitados por las llaves, es técnicamente posible escribir el programa en una sola línea:

```js
if (edad >= 18) { console.log("Eres mayor de edad") } else { console.log("Eres menor de edad") }
```

Solo que claro, el programa se vuelve ligeramente ilegible. En [[Python]] esto no es posible. La única opción es la siguiente:

```py
if edad >= 18:
	print("Eres mayor de edad")
else:
	print("Eres menor de edad")
```
