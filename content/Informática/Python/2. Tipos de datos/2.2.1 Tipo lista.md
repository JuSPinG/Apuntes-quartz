Veamos un ejemplo de una lista en Python.

```py
nombres = ["Juan", "Guille", "Albano"]
```

Esta es una lista de nombres, su sintaxis es sencilla: únicamente hay que introducir sus elementos entre comas. Las comillas, en este caso, son usadas para declarar que los nombres son de tipo texto, y no de tipo numérico o variables. Veamos otros ejemplos:

```py
numeros = [3, 4, 1, 10, 9, 5]
fechas_varias = [20250416, [2025, 4, 16], "2025/04/16"]
```

Como podemos ver, las listas admiten todo tipo de datos dentro, ya sean números, otros datos complejos, o textos.

# Añadir elementos

## Simples

Existen muchos métodos con las listas, y son muy útiles, pero como son más avanzados, los veremos más adelante. Por lo pronto, existen varias formas de introducir elementos en una lista. Con el ejemplo de antes:

```py
numeros = numeros + [2, 6, 7]
print(numeros)
```
```py
[3, 4, 1, 10, 9, 5, 2, 6, 7]
```

Pero también podemos usar el método `append()`:

```py
numeros.append(8)
print(numeros)
```
```py
[3, 4, 1, 10, 9, 5, 2, 6, 7, 8]
```

Ambas forman añaden un elemento a su última posición. Si queremos añadirlo en otro lugar deberemos de especificarlo con índices.

Por último, la función `len()` nos ayuda medir cuántos elementos hay en la lista (o la cadena), _len_ de longitud:

```py
print(len(numeros)) # 10, 10 empezando por el 0
```

## Otras listas

Al igual que hacemos listas de elementos simples, podemos hacer listas de elementos complejos: listas de listas (o de incluso otras estructuras que no hemos visto). Veamos un ejemplo:

```py
a = [1, 2, 3]
b = [4, 5, 6]
c = [7, 8, 9]
x = [a, b, c]
print(x) # [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```
