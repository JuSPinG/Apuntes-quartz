Este apartado es sencillo, sobre todo porque la asignación ya la hemos visto un poco por encima. ¿Por qué sumar y luego guardar si podemos combinar ambas operaciones? Veamos un ejemplo:

```py
contador = 0

# Opción 1:
contador = contador + 1

Opción 2:
contador += 1
```

La opción 2 es más elegante, y ambas con equivalentes. Lo mismo sucede para los operadores:

1. `-=`.
2. `*=`.
3. `/=`.
4. `%=`.
5. `**=`.
