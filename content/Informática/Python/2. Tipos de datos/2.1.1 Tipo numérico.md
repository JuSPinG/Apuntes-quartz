# Tipo entero

El tipo entero no es ni más ni menos que un número entero, y nos referimos a él comúnmente como "`int`" (de _integer_). Veamos un ejemplo:

```py
>>> 3
3
```

Ese es un número entero. Los números enteros permiten operaciones aritméticas como la suma:

```py
>>> 3+2
5
```

Los operadores aritméticos posibles son los siguientes:

| Signo | Nombre                 | Ejemplo      |
| ----- | ---------------------- | ------------ |
| `+`   | Suma                   | `3+2 == 5`   |
| `-`   | Resta                  | `3-2 == 1`   |
| `*`   | Multiplicación         | `3*2 == 6`   |
| `**`  | Exponente              | `3**2 == 9`  |
| `/`   | División               | `3/2 == 1.5` |
| `//`  | División sin decimales | `3//2 == 1`  |
| `%`   | Módulo o resto         | `4%2 == 0`   |
# Tipo flotante

El tipo flotante se trata de los números racionales. Nos referimos comúnmente a este tipo con "`float`" (_float_ como abreviatura de "coma flotante"). Veamos un ejemplo:

```py
>>> 1.5
1.5
>>> 5/2
2.5
```

Estos números también son susceptibles ser operados aritméticamente. Debemos tener en cuenta siempre que su precisión puede no ser perfecta, por ejemplo:

```py
>>> 0.1+0.2
0.30000000000000004
```
