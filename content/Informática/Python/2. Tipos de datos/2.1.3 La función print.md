`print()` nos sirve para imprimir cosas por pantalla. Cuando hacemos pruebas en la terminal de Python, la función `print()` es poco utilizada pues con escribir el nombre de una variable podemos ver su contenido. En un archivo ejecutable esto cambia. A partir de ahora, todos los ejemplos serán ejecutados en este entorno.

```py
print(10) # Nos devuelve 10
```

Ya de paso, así es como se genera un comentario en Python, escribiendo un `#`. Por otro lado, solo recordar que para crear un ejecutable de Python tan solo hay que crear un archivo cuya extensión sea `py` (o `pyw`, pero eso es más adelante) y ejecutarlo usando el comando:

```cmd
python3 "{nombre del archivo}"
```
