Estos apuntes están basados en la entrada de [[5.2 Prácticas de FTP|Prácticas de FTP]].

La configuración del archivo principal de vsftpd (encontrado en `/etc/vsftpd.conf`) puede ser un poco liosa, por lo que vamos a desengranar sus directivas más importantes:

| Directiva                 | Valores  | Descripción                                                                                                                                                                                        |
| ------------------------- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `listen`                  | Booleano | Habilita la escucha del servidor en modo _standalone_ para IPv4.                                                                                                                                   |
| `listen_port`             | Entero   | Especifica por qué puerto escuchará el servidor.                                                                                                                                                   |
| `listen_ipv6`             | Booleano | Habilita la escucha del servidor en modo _standalone_ para IPv6.                                                                                                                                   |
| `anonymous_enable`        | Booleano | Permite o no que el usuario anónimo esté activo.                                                                                                                                                   |
| `anon_upload_enable`      | Booleano | Permite que el usuario anónimo pueda subir archivos, se requieren permisos de la carpeta y que esté habilitada la subida de archivos general.                                                      |
| `write_enable`            | Booleano | Permite que, en general, la subida de archivos esté permitida.                                                                                                                                     |
| `local_umask`             | Entero   | Establece cuál será la máscara predeterminada para los archivos recién creados por los usuarios. Se recomienda para pruebas la de 022.                                                             |
| `anon_other_write_enable` | Booleano | Le permite al usuario anónimo modificar archivos que no son suyos.                                                                                                                                 |
| `anon_root`               | Cadena   | Establece cuál será la ruta en la cual el usuario anónimo se encontrará encarcelado.                                                                                                               |
| `userlist_enable`         | Booleano | Habilita la lista de usuarios, ya sea de carácter privativo o autoritativo.                                                                                                                        |
| `userlist_deny`           | Booleano | Indica si la lista de usuarios será de carácter privativo o autoritativo.                                                                                                                          |
| `userlist_file`           | Cadena   | Especifica cuál será la ruta del archivo en en el que se guardarán los nombres, permitidos o negados. No se recomienda que la ruta sea `/etc/ftpusers`, pues este archivo es únicamente privativo. |
| `chroot_local_user`       | Booleano | Meterá en la cárcel a todos los usuarios que no estén en la lista que se indica con `chroot_list_file`. Si se establece en `NO`, el funcionamiento se invierte.                                    |
| `chroot_list_enable`      | Booleano | Indica si se usará una lista de nombres que son enjaulados. Si se habilita con la directiva anterior, el funcionamiento se invierte (usuarios no enjaulados).                                      |
| `chroot_list_file`        | Cadena   | Especifica dónde se encuentra el archivo con la lista de nombres.                                                                                                                                  |
| `allow_writeable_chroot`  | Booleano | Habilita que los usuarios encarcelados puedan escribir.                                                                                                                                            |
| `implicit_ssl`            | Booleano | Activa el modo seguro implícito. Es necesario acompañarlo con `listen_port`.                                                                                                                       |
| `ssl_enable`              | Booleano | Activa el modo SSL.                                                                                                                                                                                |
| `rsa_cert_file`           | Cadena   | Especifica dónde estará el archivo `crt` o `pem`.                                                                                                                                                  |
| `rsa_private_key_file`    | Cadena   | Especifica dónde estará el archivo `key`.                                                                                                                                                          |
| `nopriv_user`             | Cadena   | Indica cuál es el usuario que puede ejecutar gestiones administrativas que no requieran de privilegios.                                                                                            |
| `guest_enable`            | Booleano | Si se activa, el usuario "guest" quedará activado. Este es todo aquel que no es ni un usuario local ni el anónimo.                                                                                 |
| `guest_username`          | Cadena   | Indica cuál es el usuario que realizará cambios en el equipo de forma automática. Se combina con `nopriv_user`.                                                                                    |
| `user_sub_token`          | Cadena   | Crea una variable relacionada con el nombre del usuario. Se suele asignar a `user_sub_token=$USER`.                                                                                                |
| `local_root`              | Cadena   | Especifica cuál será la raíz de los usuarios. Perfecto para combinarlo con `local_root=/home/$USER`                                                                                                |
| `hide_ids`                | Booleano | Ayuda para manejar visualmente las IDs de los archivos y sus propietarios.                                                                                                                         |
| `log_ftp_protocol`        | Booleano | Habilita los _logs_.                                                                                                                                                                               |
