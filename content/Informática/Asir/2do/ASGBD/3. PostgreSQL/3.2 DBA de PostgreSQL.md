# 2. Creación de la Base de Datos y Tablas.

1. Crear la base de datos.
	1. Conéctate a la consola de PostgreSQL como el usuario "postgres".
		```sh
		sudo -i -u postgres
		psql
	   ```
	2. Crea una base de datos llamada EquitacionSuave y conectate a ella.
		```sql
		CREATE DATABASE EquitaciónSuave OWNER alumno;
		```
2. Crear las tablas principales.
	1. Crea una tabla llamada "jinetes" que incluya los siguientes campos:
		1. `id`: un identificador único autoincrementado para cada jinete.
		2. `nombre`: el nombre del jinete.
		3. `apellido`: el apellido del jinete.
		4. `categoría`: una cadena que representa el nivel de habilidad (e.g., Avanzado, Intermedio, Principiante).
		5. `experiencia_años`: un número entero que indica los años de experiencia.
		```sql
		CREATE TYPE categorías_jinete AS ENUM ('Principiante', 'Intermedio', 'Avanzado'); -- Lo usaré para crear la categoría
		CREATE TABLE jinetes(
			id SERIAL PRIMARY KEY,
			nombre VARCHAR(50),
			apellido VARCHAR(100),
			categoría categorías_jinete, -- La razón por la que lo implemento así es para que ocupe menos espacio, es una buena práctica
			experiencia_años INT2
		);
		```
	2. Crea una tabla llamada "caballos" que incluya los siguientes campos
		1. `id`: un identificador único autoincrementado para cada caballo.
		2. `nombre`: el nombre del caballo.
		3. `raza`: la raza del caballo.
		4. `edad`: un número entero que representa la edad del caballo. 
		5. `jinete_id`: una referencia al id de la tabla jinetes, para indicar quién es el jinete actual del caballo. 
		```sql
		CREATE TABLE caballos(
			id SERIAL PRIMARY KEY,
			nombre VARCHAR(20),
			raza VARCHAR(25),
			edad INT2,
			jinete_id INT REFERENCES jinetes(id)
		);
		```

# 7. Uso de "pgAdmin" para Administración Visual

## Paso 0: Instalar "pgAdmin"

Lo primero de todo, hay que instalar "pgAdmin". En Kali Linux solo se puede hacer con Docker o Python, yo voy a usar Python. Usaré la siguiente secuencia de comandos:

```sh
sudo apt update                                                                                                                           
sudo apt install python3-venv libpq-dev build-essential python3-dev -y # Para actualizar los paquetes, y usar los env
mkdir ~/pgadmin-env # La carpeta del env (ENtorno Virtual)
python3 -m venv ~/pgadmin-env # Habilitar en env de Python
source ~/pgadmin-env/bin/activate # # Entrar dentro del env desde la máquina
pip install pgadmin4 # Ahora, pgAdmin se instalará dentro del entorno

### SOLO SI NO SE HA INSTALADO EN ROOT ###
sudo mkdir -p /var/lib/pgadmin # Damos permisos a las carpetas críticas
sudo chown -R $USER:$USER /var/lib/pgadmin
sudo mkdir -p /var/log/pgadmin
sudo chown -R $USER:$USER /var/log/pgadmin

### FINALMENTE ###
pgadmin4
```
