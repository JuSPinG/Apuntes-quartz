**He aquí una pequeña configuración de inicio en PostgreSQL.**

Actualiza los repositorios del sistema e instala PostgreSQL.

```sh
sudo apt install postgresql
```

Inicia el servicio de PostgreSQL y configura el servicio para que se inicie automáticamente cada vez que se arranque el sistema.

```sh
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

Cambia al usuario `postgres` y abre la consola de PostgreSQL.

```sh
getent passwd | grep postgresql # Para comprobar que existe
sudo -i -u postgres
psql
```

Ahora vamos a crear alguna configuración en SQL:

```sql
CREATE USER {nombre} WITH PASSWORD '{contraseña}';
CREATE DATABASE {nombre de la base} OWNER {nombre};

GRANT ALL PRIVILAGES ON DATABASE {nombre de la base} TO {nombre};
```

Por último entramos con:

```sh
exit
psql -U {nombre} -d {nombre de la base} -h localhost
```

He aquí la sintaxis de una tabla básica:

```sql
CREATE TABLE jugadores(
	id SERIAL PRIMARY KEY,
	nombre VARCHAR(50),
	altura INT
);

CREATE TABLE camisetas(
	id SERIAL PRIMARY KEY,
	talla VARCHAR(3),
	texto VARCHAR(200),
	jugador_id INT REFERENCES jugadores(id)
);

INSERT INTO jugadores (nombre, altura) VALUES ('Ana', 156), ('Jimena', 200), ('Luisa', 160);
INSERT INTO camisetas(talla, texto, jugador_id) VALUES ('xl', 'media', 1), ('l', 'portera', 1), ('m', 'delantera', 3);

SELECT * FROM jugadores WHERE altura >= 170;
SELECT talla FROM camisetas WHERE jugador_id IN (SELECT id FROM jugadores WHERE altura < 170);
UPDATE jugadores SET altura = 190 WHERE nombre = 'Ana';
DELETE FROM camisetas WHERE jugador_id IN (SELECT id FROM jugadores WHERE nombre = 'Luisa');
```
