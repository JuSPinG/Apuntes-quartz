Esta instalación se realizará en un Kali Linux.

```sh
sudo apt update
sudo apt upgrade -y
sudo apt install mariadb-client mariadb-server
sudo systemctl start mariadb
sudo systemctl enable mariadb
sudo mariadb -u root -p # Comprobar que efectivamente podemos entrar
```
