Los usuarios se crean con la siguiente sentencia:

```SQL
CREATE USER '{nombre de usuario}'@'{ip de acceso}' IDENTIFIED BY '{contraseña}';
```

Este método de acceso recuerda bastante al que podemos encontrar en [[1.1 Ataque de diccionario#Repaso rápido de SSH]]. 

> [!info]- Cómo contener una sentencia de MySQL dentro de una sentencia de Bash.
> Cabe recalcar que todas las sentencias de MySQL que se ejecuten, pueden ser contenidas en una sentencia en Bash, de la siguiente forma:
> ```sh
> mysql -u root -p -e "{sentencia de MySQL}"
> ```

A estos usuarios recién creados se puede acceder con el siguiente comando:

```SQL
SELECT user, host FROM mysql.user;
```

Para añadir permisos, podemos escribir en la terminal lo siguiente:

```SQL
GRANT {tipo de permiso} ON {nombre de base de datos}.{nombre de tabla} TO '{nombre de usuario}'@'{ip de acceso}';
FLUSH PRIVILEGES; --- esto confirma los cambios
```

> [!summary]- Lista de permisos en MySQL.
> 1. `CREATE`: Podrá crear bases y tablas de datos.
> 2. `DROP`: Podrá eliminar bases y tablas de datos.
> 3. `INSERT`: Podrá ingresas datos en sus tablas.
> 4. `UPDATE`: Podrá modificar datos en sus tablas.
> 5. `DELETE`: Podrá eliminar datos en sus tablas.
> 6. `SELECT`: Podrá seleccionar datos de las tablas.
> 7. `GRANT OPTION`: Podrá modificar permisos a otros usuarios.
> 8. `ALL PRIVILEGES`: Todos los anteriores.
> Esta lista recuerda a las opciones posibles dentro de la gestión de las tablas en un base de datos. Se puede encontrar más información aquí: [[Resumen de sentencias en SQL]].

Para ver sus permisos, ejecutamos la siguiente sentencia:

```SQL
SHOW GRANTS FOR '{nombre de usuario}'@'{ip de acceso}';
```

Si solo se escribe `SHOW GRANTS;`, entonces, te dice tus propios permisos.

Con:

```SQL
REVOKE DELETE ON {nombre de la base de datos}.{nombre de la tabla} FROM '{nombre de usuario}'@'{ip de acceso}';
```

Puedes eliminar los permisos específicos de un usuario.

Para ingresar con otro usuario, puedes ejecutar el comando:

```sh
sudo mysql -u {usuario} -p
```

Y para cambiar su contraseña, la sentencia es:

```SQL
ALTER USER '{nombre de usuario}'@'{ip de acceso}' IDENTIFIED BY '{nueva contraseña}';
```
