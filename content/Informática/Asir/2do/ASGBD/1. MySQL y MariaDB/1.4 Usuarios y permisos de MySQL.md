# Preparación

Primero crea esta base de datos inicial de 3 tablas llamada red social:

| usuario                   | grupo                      | comentario               |
| ------------------------- | -------------------------- | ------------------------ |
| PK `id_usuario` (`INT`)   | PK `id_grupo` (`INT`)      | PK `id_comentario` (INT) |
| `nombre` (`VARCHAR`)      | `nombre_grupo` (`VARCHAR`) | FK `usuario_id` (`INT`)  |
| `email` (`VARCHAR`)       | FK `creador_id` (`INT`)    | FK `grupo_id` (`INT`)    |
| `fecha_registro` (`DATE`) | `fecha_creacion` (`DATE`)  | `texto` (`TEXT`)         |

Sentencia para la tabla `usuario`:

```SQL
CREATE TABLE usuario(
	id INT PRIMARY KEY,
	nombre VARCHAR(15) NOT NULL,
	email VARCHAR(30) NOT NULL,
	fecha_registro DATE NOT NULL
);
```

Sentencia para crear la tabla `grupo`:

```SQL
CREATE TABLE grupo(
	id_grupo INT PRIMARY KEY,
	nombre_grupo VARCHAR(15),
	creador_id INT NOT NULL,
	FOREIGN KEY (creador_id) REFERENCES usuario(id)
);
```

Sentencia para crear la tabla `comentario`:

```SQL
CREATE TABLE comentario(
	id_comentario INT PRIMARY KEY,
	texto VARCHAR(254) NOT NULL,
	usuario_id INT NOT NULL,
	grupo_id INT NOT NULL,
	FOREIGN KEY (usuario_id) REFERENCES usuario(id),
	FOREIGN KEY (grupo_id) REFERENCES grupo(id_grupo)
);
```
