# Instalar MongoDB

Vamos a usar Docker para acceder a la base de datos. No voy a explicar el proceso completo, pero adjuntaré algún comando importante:

```sh
# Crear el contenedor
sudo docker run -d --name mongodb -p 27017:27017 -e MONGO_INITDB_ROOT_USERNAME=admin -e MONGO_INITDB_ROOT_PASSWORD=admin123 -v /home/marcos/MongoDB/mongo_data:/data/db mongo

# Mostrar los contenedores
sudo docker ps -a

# Completar la instalación para acceder
wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | sudo gpg --dearmor -o /usr/share/keyrings/mongodb-archive-keyring.gpg
echo "deb [ arch=amd64 signed-by=/usr/share/keyrings/mongodb-archive-keyring.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt install -y mongodb-mongosh

# Para iniciar el contenedo y entrar, si no está iniciado ya, podemos ejecutar
sudo docker start mongodb

# Para entrar a la base de datos. Requiere que el contenedor esté activo
mongosh -u admin -p admin123 --authenticationDatabase admin
```

# Sentencias básicas de MongoDB

Algunas sentencias básicas de MongoDB son:

```js
// Usa y/o crea una base de datos
use alumnos

// Inserta un dato
db.alumnos.insertOne({
	nombre: "Juan",
	edad: 25,
	ciudad: "Madrid"
})

// Inserta varios datos
db.alumnos.insertMany([
	{ nombre: "Ana", edad: 30, ciudad: "Barcelona" },
	{ nombre: "Luis", edad: 28, ciudad: "Sevilla" }
])

// Muetra todos los datos
db.alumnos.find()

// Muestra un dato específico
db.aslumnos.find([nombre: "Ana"])

// Cambia un dato
db.alumnos.updateOne(
	{ nombre: "Juan" },
	{ $set: { edad: 26 } }
)

// Cambiar varios datos
db.alumnos.updateMany(
	{ ciudad: "Madrid" },
	{ $inc: { edad: 1 } }
)

// Eliminar un dato
db.alumnos.deleteOne({ nombre: "Juan" })

// Eliminar varios datos
db.alumnos.deleteMany({ ciudad: "Sevilla" })
```
