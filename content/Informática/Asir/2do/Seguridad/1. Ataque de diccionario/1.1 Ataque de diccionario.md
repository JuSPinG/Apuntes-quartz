## Funcionamiento de Hydra

Hydra es una herramienta usada para hacer ataques de fuerza bruta en SSH, será perfecto para nuestra tarea. Por defecto, viene instalado en Kali Linux, por lo que omitiré la instalación en este tutorial (no lo instalo porque ya lo tengo, pero sería con el comando `sudo apt install hydra -y`).

Haremos el ataque al siguiente usuario:

1. IP: `127.0.0.0`.
2. Usuario: `acceso`.
3. Contraseña (sabida de antemano): adm.

Por lo que el comando que podríamos usar para hackear este perfil es:

```sh
hydra -l acceso -p adm ssh://127.0.0.0
```

Los campos de usuario y contraseña, en este caso, pueden ser variables, por lo que los parámetros `-l` y `-p` pueden ser sustituidos por sus variantes en mayúsculas, para que sustituya el campo por un índice variable de una lista, es decir:

```sh
hydra -l acceso -P contrasena.txt ssh://127.0.0.0
```

Prueba cada posible contraseña almacenada en `contrasenas.txt`, asumiendo que su contenido es, únicamente "adm", probará esa contraseña y acertará en su primer intento.

La genialidad del ataque surge cuando unimos ambas herramientas.

## Generar diccionarios con Pydictor

Pydictor soporta varios argumentos, como el que permite generar todas las combinaciones posibles entre 3 y 4 letras, ya sean mayúsculas o minúsculas. En ese conjunto, casualmente, se encuentra mi contraseña (entre "aaa" y "ZZZZ").

```sh
./pydictor.py --len 3 4 -base Lc
```

1. `./pydictor.py`: Ejecuta el programa.
2. `--len 3 4`: La longitud mínima y máxima de la cadena.
3. `-base Lc`: Especifica qué tipos de caracteres va a generar el programa, en este caso, mayúsculas y minúsculas.

Por lo que el archivo generado `base_{número}.txt`, se puede usar para hackear.

## Formulario Web

Lo primero de todo, se necesitará tener Xampp instalado, se puede conseguir con `sudo apt install xampp`. Y será necesario iniciar el servicio (yo lo ejecuto fácilmente con `sudo /opt/lampp/manager-linux-x64.run`). Luego, será necesario descargarse un servidor al que atacar. Este será [DVWA](https://github.com/digininja/DVWA), y lo instalaremos de la siguiente forma:

```sh
cd /opt/lampp/htdocs
git clone https://github.com/digininja/DVWA
```

A continuación, será necesario iniciar los servicios de Xampp, y seguir las instrucciones para la instalación completa del servidor, que se pueden encontrar en http://localhost/DVWA/instructions.php.
