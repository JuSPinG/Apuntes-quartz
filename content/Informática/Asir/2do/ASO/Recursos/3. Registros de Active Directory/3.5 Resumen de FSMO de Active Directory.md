# Roles a nivel de bosque
## Maestro de Esquema (_Schema Master_)

Controla el **esquema de Active Directory**, que es el "plano" de la base de datos. Define los objetos (usuarios, grupos) y sus atributos. Solo este rol puede realizar cambios en el esquema.
## Maestro de Nombres de Dominio (_Domain Naming Master_)

Gestiona la creación y eliminación de dominios en el bosque. Sin este rol, no se pueden añadir nuevos dominios ni eliminar los existentes. A cada dominio agregado se le asigna un espacio de nombres, cuando un controlador de dominio es integrado en un Bosque, su Maestro RID se ocupa de adquirir un **Domain SID** y el **RID pool** que no exista en el Bosque.
# Roles a Nivel de Dominio

Estos roles existen en cada dominio del bosque.
## Maestro de RID (_RID Master_)

Se encarga de asignar bloques de **identificadores relativos (RIDs)** únicos a cada controlador de dominio, garantizando que cada objeto de seguridad creado en el dominio tenga un **SID** (Security Identifier) único.
## Emulador de PDC (_PDC Emulator_)

Actúa como el controlador de dominio principal para la compatibilidad con sistemas heredados. **Es la fuente de tiempo autoritativa** del dominio y el primer lugar donde se replican los **cambios de contraseña y las políticas de grupo.**
## Maestro de Infraestructuras 

Cargo único dentro del dominio. Es el responsable de actualizar las referencias de los objetos de los dominios para que puedan ser accedidos desde otros dominios del bosque.
