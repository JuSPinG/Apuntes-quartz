Es importante tener en cuenta que si un comando no encuentra ninguna búsqueda, entonces, falla el comando. Devuelve un error que no es un error de verdad.

Para obtener los últimos 10 críticos de errores, advertencias del sistema, y seguridad.

```Shell
Get-EventLog -LogName System -EntryType Error -Newest 10
Get-EventLog -LogName Security -EntryType Error -Newest 10
Get-EventLog -LogName System -EntryType Warning -Newest 15
```

Si no hay eventos que coincidan, entonces, la búsqueda falla.

Para obtener críticos, errores y advertencias todo en uno:

```Shell
Get-WinEvent -LogName System -MaxEvents 30 -FilterXPath '*/System/Level<4'
```

Solamente críticos:

```Shell
Get-WinEvent -LogName System -MaxEvents 10 -FilterXPath '*/System/Level=1'
```

Para saber el evento 1074 de apagado de un equipo:

```Shell
Get-WinEvent -LogName System -ID 1074 -MaxEvents 1 -ComputerName PC001 | Select-Object TimeCreated, Message
```

El evento de mayor gravedad que puedes escribir crear manualmente con `Write-EventLog` es Error. Usaremos este tipo y el registro de Aplicación, que es donde se suelen escribir eventos personalizados (el registro de Sistema está generalmente reservado para el propio sistema operativo).

```Shell
Write-EventLog -LogName "Windows PowerShell" -Source "PowerShell" -EventID 999 -EntryType Error -Message "Falsa Alarma"
```
