# [AREPL for Python](https://marketplace.visualstudio.com/items?itemName=almenon.arepl)

Es una herramienta que nos permite _debuggear_ nuestro programa en directo, señalando qué variables se forman y qué _outputs_ se expulsan.

![[Ejemplo de uso de AREPL.png]]

# [Pylance](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance)

Esta extensión trae un conjunto de utilidades a Python, como sugerencias, detección de errores avanzada, importaciones automáticas, y compatibilidades con IntelliCode o Jupyter Notebooks (aunque estas son herramientas que no creo que usemos).

![[Sugerencia de Pylance.png]]

Esa bombilla que aparece, al ser pulsada, muestra más recomendaciones de Pylance.

# [Python](https://marketplace.visualstudio.com/items?itemName=ms-python.python)

El paquete de "Python" para VSC trae consigo 2 extensiones más, [[#[Pylance](https //marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance)|Pylance]] es una de ellas y también trae un _debugger_. Yo suelo usar esta extensión, la principal del paquete, para hacer un uso correcto del controlador de versiones, y para poder ejecutar el programa mediante un botón que aparece en la esquina superior derecha.
