# Qué voy a necesitar?

1. Sistema de peticiones a las bases de datos y actualización de los datos locales.
2. Uso de SQLite para guardar toda la información.
3. Uso de librerías de Machine Learning (Tensorflow) para el procesamiento de datos.
4. Ajustar la red neuronal, pues X datos de la bolsa interfieren en Y. Será necesario saber que ristras de datos son necesarias para hacer la predicción.
5. Creación de una interfaz gráfica en la web con uso de frameworks como DJango o Flask.
6. Comprobar la eficiencia del modelo.
7. Si da tiempo, entrar en un simulador de bolsa y hacerme de oro.
