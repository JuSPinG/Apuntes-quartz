# Definitions

Hardware is the phyical, tangible parts of a computer, like the monitor, keyboard, and internal components (CPU, RAM).

Software is the set of instructions, pograms, and data that tells the hardware what to to, such as an operating system, web browser, or a video game.

# Common parts of PC

1. _Monitor_: Monitor.
2. _Case_: Torre (carcasa).
3. _Motherboard_: Placa base.
4. CPU: Unidad central de procesamiento.
5. _Main memory_ (RAM): Memoria principal (Memoria de acceso aleatorio).
6. _Expansion cards_: Ranuras de expansión.
7. _Power supply unit_: Fuente de alimentación.
8. _Optical disk drive_: Disco duro HDD.
9. _Hard disk drive_: Disco duro SSD.
10. _Keyboard_: Teclado.
11. _Mouse_: Ratón.

# Computer peripheral devices

1. _Printer_: Impresora.
2. _Speakers_: Altavoces.
3. _Wireless mouse_: Ratón inalámbrico.
4. _USB Flash drive_: USB _booteable_.
5. _Headohones_: Cascos.
6. _Webcam_: Cámara web.
7. _Scanner_: Escaner.

# Types of software

1. _System software_ (_Software_ del sistema): Handles file management program execution, and systemd resource allocation.
	1. Android.
	2. iOS.
	3. Linux.
	4. Microsoft Windows.
2. _Programming software_ (_Software_ programable): Used by programmers as translator programs. They are facilitator software to used to translate programming languages into machine language code.
	1. Like Notepad++ or VSC.
3. _Application software_ (Aplicación _software_): Is designed to perform specific jobs like writing, paiting, sudyng, or gaming. End users are its main focus.
	1. Word.
	2. Excel.
	3. VLC.
	4. Email.
4. _Driver software_ (los _drivers_): They operate and control devices and peripherals plugged into a computer.
	1. Like Canon TSS100 series.
