# Creando la base de datos

Lo primero de todo, deberemos crear una base de datos, pues de eso mismo va el juego. Lo haremos de acuerdo a la siguiente imagen.

![[Esquema de base de datos.png]]

**Creación de la base de la base de datos**:
```sql
CREATE DATABASE gestion_juegos
USE gestion_juegos;
```

**Creación de las tablas**:
```sql
-- Tabla GAMES
CREATE TABLE GAMES (
	ID INT AUTO_INCREMENT PRIMARY KEY,
	Titulo VARCHAR(100) NOT NULL
);

-- Tabla PLAYERS
CREATE TABLE PLAYERS (
	ID INT AUTO_INCREMENT PRIMARY KEY,
	Alias VARCHAR(50) NOT NULL
);

-- Tabla PARTIDAS
CREATE TABLE PARTIDAS (
	ID INT AUTO_INCREMENT PRIMARY KEY,
	Nombre VARCHAR(30),
	Descripción VARCHAR(20),
	ID_GAME INT,
	ID_PLAYER1 INT,
	ID_PLAYER2 INT,
	FOREIGN KEY (ID_GAME) REFERENCES GAMES(ID) ON DELETE CASCADE,
	FOREIGN KEY (ID_PLAYER1) REFERENCES PLAYERS(ID) ON DELETE CASCADE,
	FOREIGN KEY (ID_PLAYER2) REFERENCES PLAYERS(ID) ON DELETE CASCADE
);
```

**Inserción de los datos**:
```sql
-- Datos de prueba
INSERT INTO GAMES (Titulo) VALUES ('League of Legends'), ('FIFA 24'), ('Valorant');
```

```php
===== partidas_insert.php =====

<?php
require 'db.php';
$mensaje = "";

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $id_game = (int)$_POST['id_game'];
    $p1 = (int)$_POST['p1'];
    $p2 = (int)$_POST['p2'];
    $descripcion = trim($_POST['descripcion']);

    if ($p1 === $p2) {
        $mensaje = "Los jugadores deben ser distintos.";
    } else {
        try {
            $stmt = $pdo->prepare("
                INSERT INTO PARTIDAS (ID_GAME, ID_PLAYER1, ID_PLAYER2, Descripción)
                VALUES (?, ?, ?, ?)
            ");
            $stmt->execute([$id_game, $p1, $p2, $descripcion]);
            $mensaje = "Partida registrada correctamente.";
        } catch (Exception $e) {
            $mensaje = "Error al guardar: " . $e->getMessage();
        }
    }
}

$games = $pdo->query("SELECT ID, Titulo FROM GAMES ORDER BY Titulo")->fetchAll(PDO::FETCH_ASSOC);
$players = $pdo->query("SELECT ID, Alias FROM PLAYERS ORDER BY Alias")->fetchAll(PDO::FETCH_ASSOC);
```
