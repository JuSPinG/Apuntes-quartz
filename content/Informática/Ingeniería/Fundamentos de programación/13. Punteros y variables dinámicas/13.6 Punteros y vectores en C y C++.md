# 16.3.3 Matrices y vectores de punteros

Enlace: [[Fundamentos de programación.pdf#page=383&selection=151,0,161,8|Fundamentos de programación, página 383]].

Un vector de punteros es como una matriz:

```c
/*-- Usando matrices --*/
typedef int T_Fila[15];
typedef T_Fila T_Matriz[10];

T_Matriz matriz;

matriz[3][5] = 27;

/*-- Usando punteros --*/
typedef int* T_Puntero,
typedef T_Puntero T_Matriz[10];

T_Matriz matriz;

matriz[3][5] = 27;

/*-- Para inicializar lel vector de punteros --*/
for (int k = 0; k <= 10; k++) {
  matriz[k] = new T_Fila;
}
```

![[Matrices y vectores de punteros.png]]

Yo no conozco el motivo por el que una persona usaría el segundo método, pero, por algún casual, ahí está. Bueno, al parecer, permite la construcción de una matriz en la que todas las filas no tengan la misma longitud, lo que permite la construcción de diccionarios.

```c
typedef char* T_Palabra;
typedef T_Palabra T_Diccionario[7];

T_Diccionario nombreDias = {
  "Lunes",
  "Martes",
  "Miércoles",
  "Jueves",
  "Sábado",
  "Domingo"
};
```
