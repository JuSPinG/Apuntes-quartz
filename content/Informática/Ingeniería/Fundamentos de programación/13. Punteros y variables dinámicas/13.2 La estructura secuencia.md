Muy similar las [[listas]] en Python.

Es importante tener en cuenta los cursores. Un cursor es una variable que señala a un elemento de la sentencia.

El cursor señala distintos elementos, puede ser el inicial, de recorrido, y de final.

![[Ejemplo del cursor.png]]

Ahora, gracias a esta estructura indefinidamente larga, se pueden reescribir algunos programas de forma más cómoda. Supongamos una lista de números a ordenar.

- Leer números e imprimirlos en orden →
	- Imprimir los números y almacenarlos en orden.
	- Imprimir los números almacenados.

```c
/* Leer los números y almacenarlos en orden */

iniviar la secuencia, vacía
Leer un número
while (no es cero) {
  Almacenar el número, en orden
  Leer un número
}
```

- Almacenar el número, en orden →
	- Buscar la posición que le corresponde.
	- Insertarlo en su posición.

```c
/* Buscar la posición que le corresponde */

Iniciar cursor
while (no Fin && número > cursor) {
  Avanzar cursor
}
```

```c
/* Imprimir los números almacenados */

Iniciar cursor

while (no Fin) {
  Imprimir cursor
  Avanzar cursor
}
```
