# 5.1.1 Representación de la estructura de un programa

Enlace: [[Fundamentos de programación.pdf#page=108&selection=192,0,210,8|Fundamentos de programación, página 108]].

Tradicionalmente, se representan usando "diagramas de flujo", con aplicaciones como PSeInt.

Podemos encontrar elementos básicos, como acciones y condiciones. Las acciones se representan mediante rectángulos, mientras que las condiciones con rombos: 

![[Ejemplo diagrama de flujo.png]]

Las acciones, como elemento que son, tienen 2 flechas, una entrante y otra saliente. En cambio, las condiciones, como elemento que son, tienen 3 flechas, una entrante y 2 salientes.

En los diagramas de flujo, hay 3 sentencias clave: secuencia, sección, e iteración.
# 5.1.2 Secuencia

Enlace: [[Fundamentos de programación.pdf#page=109&selection=82,0,87,1|Fundamentos de programación, página 109]].

La secuencia es una sucesión de acciones, de sentencias elementales del lenguaje.

![[Ejemplo secuencia.png]]
# 5.1.3 Selección

Enlace: [[Fundamentos de programación.pdf#page=110&selection=8,0,14,6|Fundamentos de programación, página 110]].

Consiste en la ejecución de una u otra acción en función de una determinada condición, que se analiza en la entrada de la estructura. La sentencia `if` de toda la vida.

![[Ejemplo selección.png]]
# 5.1.3 Iteración

Enlace: [[Fundamentos de programación.pdf#page=110&selection=137,0,139,9|Fundamentos de programación, página 110]].

Consiste en la repetición de una acción mientras se cumple una determinada condición. El `for` o `while` de toda la vida.

![[Ejemplo iteración.png]]

# 5.1.5 Estructuras anidadas

Enlace: [[Fundamentos de programación.pdf#page=111&selection=24,0,42,2|Fundamentos de programación, página 111]].

Las sentencias se pueden anidar, generando cada vez manejos de flujo más complejos. Mediante los "refinamientos sucesivos" se definen inicialmente las estructuras más externas del programa y en los pasos sucesivos se va detallan la estructura de cada acción compuesta.
