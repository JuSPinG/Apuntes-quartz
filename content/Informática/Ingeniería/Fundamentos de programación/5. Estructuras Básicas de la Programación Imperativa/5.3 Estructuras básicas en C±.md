# 5.3.1 Secuencia

Enlace: [[Fundamentos de programación.pdf#page=116&selection=67,0,69,9|Fundamentos de programación, página 116]].

Una secuencia es una sucesión de sentencias.

$$\texttt{Secuencia ::= \{Sentencia\}}$$
# 5.3.2 Sentencia `if`

Enlace: [[Fundamentos de programación.pdf#page=116&selection=195,0,199,2|Fundamentos de programación, página 116]].

En C±, la sentencia `if` tiene el siguiente formato:

```c
if (Condición) {
  Acción A;
} else {
  Acción B;
}
```
# 5.3.3 Sentencia `while`

Enlace: [[Fundamentos de programación.pdf#page=119&selection=239,0,249,5|Fundamentos de programación, página 119]].

El `while` genera un bucle si se da una condición. En cada repetición del bucle, la condición se comprueba.

```c
while (Condición) {
  Acción;
}
```
# 5.3.4 Sentencia `for`

Enlace: [[Fundamentos de programación.pdf#page=120&selection=184,0,188,3|Fundamentos de programación, página 120]].

La sentencia `for` ejecuta un bucle un número determinado de veces. Cuántas veces se va a ejecutar se especifica y se controla de forma mucho más exacta que con la [[#5.3.3 Sentencia `while`|sentencia while]].

```c
for (int Índice = Inicial; Índice <= Final; Índice++) {
  Acción;
}
```
