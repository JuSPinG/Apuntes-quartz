A la hora de meter un nuevo elemento en una lista, puede llegar a ser importante que se mantenga el orden inicial, ya sea añadiendo dicho elemento al principio o al final, o incluso, si es un orden lógico, que se inserte por el medio. Es importante tener en cuenta que el vector debe de tener espacio para poder llevar a cabo esta operación.

![[Ejemplo inserción elemento.png]]

Así podría ser el código:

```c
while (!Final && !HuecoEncontrado) {
  DesplazarElemento;
  PasarSiguienteElemento;
}
InsertarElemento;
```

Ahora, se pone a prueba:

```c
typedef ... T_Elemento ...;

void Insertar(T_Elemento v[], int N, T_Elemento elemento) {
  /*
  PRE: v[0, ..., N - 1] está ordenado
  */
  int j = N;

  /*
  INVARIANTE
  */
  while (j > 0 && elemento < v[j-1]) { /* Cuidado con elemento < v[j - 1] && j > 0, pues entonces, se podría evaluar v[0-1] */
    v[j] = v[j-1];
    j--;
  }
}
v[j] = elemento;

/*
POST: v'[0, ... N] está ordenado y contiene los valores v[0, ..., N - 1] más el elemento nuevo
*/
```
