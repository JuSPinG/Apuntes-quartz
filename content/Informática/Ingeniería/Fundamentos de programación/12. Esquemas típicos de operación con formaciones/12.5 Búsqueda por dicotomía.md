Si los datos están en ordenados, es de gran utilidad empezar a buscar en la primera o segunda mitad. Entonces, se identifica el elemento a buscar si se da con él, o solo queda un elemento por examinar (pues se asume que entonces es ese). A esto se le llama búsqueda por dicotomía.

```c
iniciar operación;

while (quedan elementos por examinar y no se ha encontrado ninguno aceptable) {
  elegir el elemento central y ver si es aceptable;
}
completar operación;
```

```c
typedef ... T_Elemento ...;

int Indice( T_Elemento buscado, const T_Elemento v[], int N ) {
  /*
  PRE: v está ordenado
  */
  int izq, dch, mitad, pos;
  izq = 0; dch = N-1; pos = -1;

  /*
  INVARIANTE: el elemento buscado, si existe, está en la zona v[izq..dch]
  INVARIANTE: ∀k ∈ (0..izq − 1) • (v[k] < buscado) ∧ ∀k ∈ (dch + 1..N − 1) • (v[k] > buscado) 
  VARIANTE: dch − izq + 1
  */
  while (pos < 0 && izq <= dch) {
    mitad = (izq + dch) / 2;
    if (v[mitad] == buscado) {
      pos = mitad;
    } else if (v[mitad] < buscado) {
      dch = mitad - 1;
    } else {
      izq = mitad + 1;
    }
  }

  return pos;
  /*
  POST: pos ≥ 0 → v[pos] == buscado ∧ pos < 0 → buscado ∉ v[0..N − 1]
  */
}
```
