Enlace: [[Fundamentos de programación.pdf#page=324&selection=8,0,14,9|Fundamentos de programación, página 324]].

Consiste en la operación de todos (o casi todos) los elementos de una formación. Suele tener esta forma:

```c
iniciar operación;

while (quedan elementos sin tratar) {
  elegir uno de ellos y tratarlo;
}

completar operación;
```

Si el tratamiento de los elementos admite una operación por índice numérico, entonces se recomienda usar un `for`:

```c
const int N = ...;

typedef ... T_Elemento ...;
typedef T_Elemento T_Vector[N];

T_Vector v;
...
iniciar operacion;

for (int i = 0; i < N; i++) {
  tratar v[i];
}
completar operación;
```

Ahora, un caso real:

```c
float SumaV(const float v[], int N) {
  float suma = 0;

  /*
  INVARIANRE: suma = \sum v [0, ..., i - 1]
  */
  for (int i = 0; i < N; i++) {
    suma = suma + v[i];
  }

  return suma;
  /*
  POST: SumaV(v, N) = \sum v [0, ..., N -1]
  */
}
```

En este caso, no hay precondición porque esta función resulta siempre verdadera (dentro de los márgenes dados), incluso independientemente del tamaño del vector.
