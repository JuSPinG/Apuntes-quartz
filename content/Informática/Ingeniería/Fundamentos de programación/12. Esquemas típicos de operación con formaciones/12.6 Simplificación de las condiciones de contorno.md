# 12.6.1 Técnica del centinela

Enlace: [[Fundamentos de programación.pdf#page=336&selection=154,0,174,2|Fundamentos de programación, página 336]].

A veces, con esto de los bucles, un se puede motivar y llegar a posiciones fuera de dicho bucle. Si eso sucede, es necesario hacer una condición doble para saber si se ha alcanzado el final del vector.

Por eso, se añade un elemento «centinela» al principio o al final del vector, que da el aviso para finalizar la búsqueda.

```c
iniciar operación (colocar el centinela);

while (no se ha encontrado un elemento aceptable) {
  elegir otro elemento y ver si es aceptable
}
completar operación (si se ha encontrado el centinela, indicar fallo en la búsqueda);
```

Y así se implementaría de forma más práctica:

```c
typedef ... T_Elemento ...;

int Indice(T_Elemento buscado, const T_Elemento v[], int N) {
  int pos = 0;

  v[N] = buscado; /* Centinela */

  while (v[pos] != buscado) {
    pos++;
  }
  if (pos >= N) { /* Si se encuentra con el centinela */
    pos = -1;
  }
  return pos;
}
```
# 15.6.2 Matrices orladas

Enlace: [[Fundamentos de programación.pdf#page=338&selection=253,0,263,4|Fundamentos de programación, página 338]].

Las matrices orladas contienen 2 filas y 2 columnas más de lo normal. En estas nuevas posiciones, se colocan centinelas.

![[Matriz orlada.png]]

Supongamos una imagen.

```c
const int ANCHO = 40;
const int ALTO = 20;
const int BORDE = -1;
const int BLANCO = 0;
const int NEGRO = 5;

typedef int Imagen_t[ALTO + 2][ANCHO + 2]
Imagen_t imagen;

/*--   Contrastar imagen   --*/
for (int i = 1; i <= ALTO; i++) {
  for (int j = 1; j <= ANCHO; j++) {
    if (imagen[i][j] <= nivel) {
      imagen[i][j] = BLANCO;
    } else {
      imagen[i][j] = NEGRO;
    }
  }
}
```

En este proceso, no se usa el contorno de la matriz, pero se tiene en cuenta pues se inician las variables principales de los bucles en 1 en vez de en 0.

Ahora, si quisiésemos ampliar la imagen (perdiendo, claramente, información), sería muy fácil gracias a las orlas:

```c
for (int = 0; i <= ALTO + 1; i++) {
  imagen[i][0] = BORDE;
  imagen[i][ANCHO + 1] = BORDE;
}
for (int i = 0; i <= ANCHO; i++) {
  imagen[0][i] = BORDE;
  imagen[ALTO + 1][i] = BORDE;
}
```
