# 8.2.1 Desarrollo descendente

Enlace: [[Fundamentos de programación.pdf#page=198&selection=339,0,343,11|Fundamentos de programación, página 198]].

El desarrollo descendente es una ampliación a la técnica de [[4.3 Desarrollo por refinamientos sucesivos|refinamientos sucesivos]], que además añade la posibilidad de definir operaciones abstractas. Entonces, en cada paso del refinamiento, se puede optar por alguna de las siguientes operaciones:

- Operación terminal (acabar el programa).
- Operación compleja, y descomponerla posteriormente.
- Operación abstracta, especificarla escribiendo más adelante el subprograma que realiza.

Es ventajoso el uso de la operación abstracta si sucede una de estas 2 cosas:

- Si evita mezclar fragmentos de programa con nivel de detalle muy diferente.
- Si evita repetir un fragmento de código.

Desafortunadamente, el primer uso acapara más memoria, mientras que el segundo utiliza mejor la memoria.
# 8.2.2 Ejemplo: Imprimir la figura de un árbol de navidad

Enlace: [[Fundamentos de programación.pdf#page=199&selection=232,0,258,3|Fundamentos de programación, página 199]].

Ahora, volvemos al árbol de navidad ([[4.5 Ejemplos de programas#^5914f9]]), y volvemos a aplicar las nuevas técnicas aprendidas.

- Imprimir árbol →
  - Imprimir copa.
  - Imprimir tronco.
  - Imprimir base.

- Imprimir copa →
  - Imprimir primeras ramas.
  - Imprimir segundas ramas.
  - Imprimir terceras ramas.

La impresión de las ramas es algo que se podría meter en una función, pues todas ellas, con su forma trapezoidal y un carácter común, es fácilmente reutilizable. Es una función parametrizada, pues solo cambia la escala del trapecio.

Por ejemplo, se puede introducir como parámetro cuántos "*" tiene la base del trapecio, a partir de ahí, es fácil saber cómo van a ser las ramas superiores, además, solo hay 3 ramas superiores, cada vez más finas.

Por lo tanto, se podría especificar la función de imprimir ramas de la siguiente manera:

```c
/*=========================================
  Especificación semántica: Procedimiento
  para imprimir 3 líneas seguidas con:
     ancho
     ancho + 2
     ancho + 4
  =========================================*/

void ImprimirRama(int ancho) { /* Especificación semántica */
  ...
}
```

Por otro lado, la función para imprimir la sección de rama entera sería la siguiente:

```c
/*==================================================
  Especificación semántica: Procedimiento para
  imprimir un rectángulo de ancho x alto asteriscos
  ==================================================*/

void ImprimirRectangulo(int ancho, int alto) { /* Especificación semántica */
...
}
```

Y con esto se podría escribir ya el programa principal:

```c
rama = 1;
for (int k = 1; k <= 3; k++) {
  ImprimirRama(rama);
  rama = rama + 2;
}

/*-- Imprimir tronco --*/
ImprimirRectángulo(1, 3);

/*-- Imprimir base --*/
ImprimirRectángulo(5, 1);
```

Un retoque final más:

Imprimir trapecio →
```c
for (int k = 1; k <= alto; k++) {
  /* Imprimir una línea del trapecio */
}
```
- Impirmir una línea del trapecio →
  - Imprimir las blancos iniciales.
  - Imprimir los asteriscos.

Por último, solo sería necesario crear la función que imprima los espacios:

```c
void ImprimirN(char c, int N) {
    ...
}
```

El programa en total sería:

```c
#include<stdio.h>

/*=================
  Constante global
  =================*/

const int centro =  20; /* Centrar cada línea */

/*=============================================================
  Procedimiento para imprimir N veces seguidas el carácter 'c'
  =============================================================*/

void ImprimirN(char c, int N) {
  for (int k = 1; k <= N; k++) {
    printf("%c", c);
  }
}

/*=========================================================
  Procedimiento para imprimir un trapecio de asteriscos
  con la base superior "ancho", altura "alto", y "avance"
  asteriscos más a casa lado en cada nueva línea
  ==========================================================*/
void ImprimirTrapecio(int ancho, int alto, int avance) {
  int anchura; /* Número de asteriscos */

  anchura = ancho;
  for (int k = 1; k <= alto; k++) {
    ImprimitN(' ', centro - anchura/2);
    ImprimitN('*', anchura);
    printf("\n");
    anchura = anchura + 2*avance;
  }
}

/*===============================================
  Procedimiento para imprimir 3 líneas seguidas
  con:
    ancho
    ancho +2
    ancho +4
  asteriscos
  ===============================================*/
void ImprimiRama(int ancho) {
  ImprimirTrapecio(ancho, 3, 1);
}

/*==========================================
  Procedimiento para imprimir un rectángulo
  de "ancho" x "alto" asteriscos
  ==========================================*/
void ImprimirRectangulo(int ancho, int alto) {
  ImprimirTrapecio(ancho, alto, 0);
}

/*===========================
  Programa principal
  ===========================*/
int main() {
  int rama; /* Ancho de rama */

  /*-- Imprimir la copa --*/
  roma = 1;
  for (int k = 1; k <= 5; k++) {
    ImprimiRama(rama);
    rama = rama + 2;
  }
  /*-- Imprimir tronco --*/
  ImprimirRectangulo(1, 3);

  /*-- Imprimir la base --*/
  ImprimirRectangulo(5, 1);
}
```
# 8.2.3 Ejemplo: Imprimir una tabla de número primos

Enlace: [[Fundamentos de programación.pdf#page=206&selection=10,0,24,6|Fundamentos de programación, página 206]].

Se busca este resultado:

![[Ejemplo números primos.png]]

Es necesario seguir con los refinamientos sucesivos:

- Imprimir la tabla de números primos de 1 a N →
  - `for (int k = 1; k <= N; k++) { /* Imprimir k si es primo */ }`
- Imprimir k si es primo →
  - `if ( /* k es primo */ ) { /* Imprimir k, tabulando */ }`

Ahora, es necesario acabar con la capa abstracta de las definiciones anteriores, esto se haría de la siguiente manera:

```c
/*====================================================
  Función para ver si un valor "k" es un número primo
  ====================================================*/
bool EsPrimo(int k) {
  /*
    PRE: k > 0
    POST: k no tiene divisores distintos de él mismo y la unidad
    POST: EsPrimo(k) = \forall d \exists (2...k-1) \cdot modulo(k, d) \neq 0
  */
/*=====================================
  Procedimiento para imprimir tabulado
  a 4 columnas de 15 caracteres
  =====================================*/
void ImprimirTabulando(int k) { /* ... */ }
}
```

Ahora pasamos la definición:

```c
/*====================================================
  Función para ver si un valor "k" es un número primo
  ====================================================*/
bool Esprimo(int k) {
  /* d es un posible divisor */
  for (int d = 2; d <= k - 1; d++) {
    if (k % d == 0) { return false; }
  }
  return true;
}
```

Para imprimir las tabulaciones, es necesario saber en qué momento de la línea se está, esto puede ser un parámetro que se tenga que pasar. En este ejemplo, se usa una variable global, de la siguiente manera:

- Imprimir k, tabulando →
	- Saltar de línea, si es necesario, imprimir k y actualizar la columna.
- Saltar de línea si es necesario →
	- `if (columna > 4) { columna = 1; printf("\n"); }`

Por lo que, el programa completo, incluyendo la definición de todos los subprogramas, es equivalente a lo siguiente:

```c
/****************************************************
* Programa: Primos
*
* Descripción:
*   Este programa imprime una tabla de números
*   primos, tabulando cada cuatro columnas
*****************************************************/
#include<stdio.h>

/*=================
  Constante global
  ================*/
const int N = 100; /* Rango de números */

/*================
  Variable gloval
  ================*/
int columna; /* Columna a imprimir */

/*====================================================
  Función para ver si un valor "k" es un número primo
  ====================================================*/
bool EsPrimo(int k) {
  for (int d = 2; d <= k-1; d++) {
    if ((k % d) == 0) {
      return false;
    }
  }
  return true;
}

/*======================================
  Procedimiento para imprimir tabulando
  a 4 columnas de 15 caracteres
  =====================================*/
void ImprimirTabulando(int k) {
  if (columna > 4) {
    columna = 1;
    printf("\n");
  }
  printf("%15d", k);
  columna++;
}

/*===================
  Programa principal
  ===================*/
int main() {
  columna = 1;
  for (int k = 1; k <= N; k++) {
    if (EsPrimo(k)) {
      ImprimirTabulando(k);
    }
  }
  printf("\n");
}
```
# 8.2.4 Reutilización

La reutilización de un código en el mismo u otros programas es algo que puede resultar muy ventajoso. Por ejemplo, volviendo a lo del árbol de navidad ([[#8.2.2 Ejemplo Imprimir la figura de un árbol de navidad]]), se pueden usar las funciones de impresión del trapezoide para imprimir nuevas figuras:

int main() {

# 8.2.5 Ejemplo: Tabular la serie de Fibonacci

Enlace: [[Fundamentos de programación.pdf#page=210&selection=331,0,343,9|Fundamentos de programación, página 210]].

Por si esta entrada no fuese lo suficientemente larga, he aquí otro punto extra.

```c
#include <stdio.h>
#include <limits.h>

// Variable global
int columna; /* columna a imprimir */

/* Procedimiento para imprimir tabulando a 4 columnas de 15 caracteres */
void ImprimirTabulando(int k) {
  if (columna > 4) {
    columna = 1;
    printf("\n");
  }
  printf("%15d", k);
  columna++;
}

/* Programa principal */
int main() {
  int termino;  /* término de la serie */
  int anterior;   /* término anterior */
  int aux;

  /* Iniciar la tabulación */
  columna = 1;

  /* Generar el comienzo de la serie */
  anterior = 0;
  termino = 1;
  ImprimirTabulando(anterior);
  ImprimirTabulando(termino);

  /* Generar el resto de la serie */
  while (INT_MAX - termino >= anterior) {
    aux = termino + anterior;
    anterior = termino;
    termino = aux;
    ImprimirTabulando(termino);
  }
  printf("\n");
  return 0;
}
```

# 8.2.6 Desarrollo para reutilización

Enlace: [[Fundamentos de programación.pdf#page=213&selection=2,0,15,1|Fundamentos de programación, página 213]].

El uso de *software* reutilizado puede traer consecuencias. Una función no estándar está pensada para un contexto de ejecución determinado, por lo que llevarla a otro entorno puede causar problemas (como que la función deje de funcionar (chiste)).

Este método tiene peculiaridad tiene sus ventajas e inconvenientes. Por un lado, se expande el número de usos del subprograma, pero su inconveniente es que se vuelve más costoso de hacer el desarrollo del subprograma, pues tiene que atender a nuevos casos de aplicaciones.

Por lo que una operación particularizada es **siempre** más sencilla de programar que una operación generalizada. Por eso, el desarrollo del [[#8.2.2 Ejemplo Imprimir la figura de un árbol de navidad]] se ha vuelto tan complejo.

Para hacerlo aún más complejo, se desarrolla un programa orientado a la reutilización de código:

```c
#include <stdio.h>
#include <limits.h>

/*===========================
  Variables globales
  ===========================*/
int TABcolumna; /* columna a imprimir */
int TABultima;  /* última columna */
int TABancho;   /* ancho de cada columna */

/*==========================================
  Procedimiento para iniciar la tabulación
  con los parámetros indicados
  ==========================================*/
void IniciarTabulacion(int columnas, int ancho) {
  TABultima = columnas;
  TABancho = ancho;
  TABcolumna = 1;
}

/*=============================================
  Procedimiento para imprimir tabulando
  a TABultima columnas de TABancho caracteres
  ============================================*/
void ImprimirTabulando(int k) {
  if (TABcolumna > TABultima) {
      TABcolumna = 1;
      printf("\n");
  }
  printf("%*d", TABancho, k);
  TABcolumna++;
}

/*===========================
  Programa principal
  ===========================*/
int main() {
  int termino;   /* término de la serie */
  int anterior;  /* término anterior */
  int aux;

  // Iniciar la tabulación
  IniciarTabulacion(6, 11);

  // Generar el comienzo de la serie
  anterior = 0;
  termino = 1;
  ImprimirTabulando(anterior);
  ImprimirTabulando(termino);

  // Generar el resto de la serie
  while (INT_MAX - termino >= anterior) {
      aux = termino + anterior;
      anterior = termino;
      termino = aux;
      ImprimirTabulando(termino);
  }
  printf("\n");
}
```

# 8.2.7 Desarrollo ascendente

Enlace: [[Fundamentos de programación.pdf#page=216&selection=118,0,122,10|Fundamentos de programación, página 216]].

El desarrollo descendente consiste en la definición de subprogramas que realicen operaciones significativas, hasta que el programa se pueda ayudar en estas. Ahora, no se definen funciones para su refinamiento, si no pensando en su uso posterior, en este y otros programas.

Por ejemplo, si se desarrollase una calculadora, que admitiese fracciones, se debería de tener en cuenta que dicha operación cuenta siempre con un numerador y un denominador. Y en vez de hacer la operación directamente, se podría usar una función intermedia que se simplifique el proceso:

```c
/*===============================
  Procedimiento para simplificar 
  la fracción n/d 
  ==============================*/
void ReducirFraccion( int & n, int & d ) {
  int divisor = 2;
  while ((divisor <= n) && (divisor <= d)) {
      while ((n % divisor == 0) && (d % divisor == 0)) {
        n = n / divisor;
        d = d / divisor;
      }
      divisor++;
  }
}

/*====================================
  Procedimiento para sumar fracciones
  n3'/d3' = n1/d1 + n2/d2 
  ===================================*/
void SumarFracciones( int n1, int d1, int n2, int d2, int & n3, int & d3 ) {
  n3 = n1*d2 + n2*d1;
  d3 = d1*d2;
  ReducirFraccion( n3, d3 );
}

/*=====================================
  Procedimiento para restar fracciones 
  n3'/d3' = n1/d1 - n2/d2 
  =====================================*/
void RestarFracciones( int n1, int d1, int n2, int d2, int & n3, int & d3 ) {
  SumarFracciones( n1, d1, -n2, d2, n3, d3 );
}

/*==========================================
  Procedimiento para multiplicar fracciones 
  n3'/d3' = n1/d1 * n2/d2 
  ==========================================*/
void MultiplicarFracciones( int n1, int d1, int n2, int d2, int & n3, int & d3 ) {
  n3 = n1*n2;
  d3 = d1*d2;
  ReducirFraccion( n3, d3 );
}
/*======================================
  Procedimiento para dividir fracciones 
  n3'/d3' = n1/d1 / n2/d2 
  ======================================*/
void DividirFracciones( int n1, int d1, int n2, int d2, int & n3, int & d3 ) {
  n3 = n1*d2;
  d3 = d1*n2;
  ReducirFraccion( n3, d3 );
}

/*===================================
  Procedimiento que lee una fracción 
  y la simplifica 
  ===================================*/
void LeerFraccion( int & n, int & d ) {
  scanf( "%d/%d", &n, &d );
  ReducirFraccion( n, d );
}

/*==========================
  Procedimiento que escribe 
  una fracción como n/d 
  ==========================*/
void EscribirFraccion( int n, int d ) {
  printf( "%d/%d\n", n, d );
}
```

Una vez que se parte desde esta base, se puede finiquitar el programa con el siguiente trozo de código:

```c
#include <stdio.h>

/* ... definiciones de los procedimientos, omitidas ... */

/* 
========================= 
Programa principal 
========================= */
int main() {
  int num = 0;   /* Acumulador: Numerador */
  int den = 0;   /* Acumulador: Denominador */
  int nn, dd;  /* Nuevo operando a utilizar */
  char operacion = ' ';  /* Tecla de operación a realizar */

  while (operacion != 'F') {
    printf(">> ");
    scanf(" %c", &operacion);

    if (operacion == '+') {
      LeerFraccion(nn, dd);
      SumarFracciones(num, den, nn, dd, num, den);
    } else if (operacion == '-') {
      LeerFraccion(nn, dd);
      RestarFracciones(num, den, nn, dd, num, den);
    } else if (operacion == '*') {
      LeerFraccion(nn, dd);
      MultiplicarFracciones(num, den, nn, dd, num, den);
    } else if (operacion == '/') {
      LeerFraccion(nn, dd);
      DividirFracciones(num, den, nn, dd, num, den);
    } else if (operacion == 'N') { /* Nuevos cálculos */
      LeerFraccion(num, den);
    } else if (operacion == '=') {
      printf("= ");
      EscribirFraccion(num, den);
    } else if (operacion != 'F') {
      printf("Pulse +, -, *, /, N, = o F\n");
    }
  }
}
```
