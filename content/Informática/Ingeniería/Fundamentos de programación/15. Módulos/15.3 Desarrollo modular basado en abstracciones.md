# 15.3.1 Implementación de abstracciones como módulos

Enlace: [[Fundamentos de programación.pdf#page=425&selection=4,0,28,2|Fundamentos de programación, página 425]].

Los TAD se pueden dividir en módulos para poder tener una separación más fuerte. Por ejemplo, el programa de Curva-C podría haberse hecho así, quedando en el programa principal el siguiente código:

```c
#include<stdio.h>
#include "CurvaC.h"
#include "Tortuga.h"
#include "Papel.h"

int main() {
  int orden;
  T_Tortuga tt;
  T_Papel pp;

  printf("Orden: ");
  scanf("%d", &orden);

  pp.PonerEnBlanco();

  /* Posición inicial de conveniencia */
  tt.Poner(8, 3, Este);
  CurvaC(orden, tt, pp);
  pp.Imprimir();
}
```

# 15.3.3 Datos encapsulados

Enlace: [[Fundamentos de programación.pdf#page=431&selection=8,0,14,12|Fundamentos de programación, página 431]].

Hay similitudes entre la declaración de un TAD y un dato encapsulado, se muestra la siguiente tabla:

| TAD                                                                          |                | Dato encapsulado              |
| ---------------------------------------------------------------------------- | -------------- | ----------------------------- |
|                                                                              | Interfaz       |                               |
| `typedef strcutc Tipo { void Operacion1(); private: UnTipo valorInterno; };` |                | `void Operacion1();`          |
|                                                                              | Implementación |                               |
| `void Tipo::Operacion1() { ... }`                                            |                | `static UnTipo valorInterno;` |
|                                                                              | Uso            |                               |
| `Tipo dato; dato.Operacion1();`                                              |                | `Operacion1();`               |

Esto hay que hacerlo si se pasa de un TAD a una programación modular o viceversa.

Cabe recalcar que los elementos de un programa son siempre externos, a no ser que se especifique lo contrario usando la palabra reservada `static`. Algo que pasaría justo igual con una estructura de datos y la palabra reservada `private`.

Con esto en mente, se puede reescribir el programa de Curva-C usando programación modular:

```c
/**********************************************************
* Interfaz de módulo: Papel
*
* Descripción:
*   Este módulo encapsula un único ejemplar de
*   dato abstracto de tipo "Papel", capaz de almacenar
*   un dibujo formado por trazos en una cuadrícula
***********************************************************/

#pragma once

void PonerEnBlanco();
void MarcarHorizontal(int x, int y);
void MarcarVetrtical(int x, int y);
void Imprimir();
```

```c
/**********************************************************
* Interfaz de módulo: Papel
*
* Descripción:
*   Este módulo encapsula un único ejemplar de
*   dato abstracto de tipo "Papel", capaz de almacenar
*   un dibujo formado por trazos en una cuadrícula
***********************************************************/

#include<stdio.h>
#include "M_Papel.h"

/*-- Elementos privados --*/

const int ANCHO = 32;
const int ALTO = 19;

typedef char MatrizMarcas[ANCHO][ALTO];

static MatrizMarcas marcasH;
static MatrizMarcas marcasV;

static bool Dentro(int x, int y) {
	return (x >= 0 && x < ANCHO && y >= 0 && y < ALTO);
}

/*-- Elementos públicos --*/

void PonerEnBlanco() {
	for (int x = 0; x < ANCHO; x++) {
		for (int y = 0; y < ALTO; y++) {
			marcasH[x][y] = ' ';
			marcasV[x][y] = ' ';
		}
	}
}

void MarcarHorizontal(int x, int y) {
	if (Dentro(x, y)) {
		marcasH[x][y] = '_';
	}
}

void MarcarVertical(int x, int y) {
	if (Dentro(x, y)) {
		marcasV[x][y] = '|';
	}
}

void Imprimir() {
	for (int y = ALTO - 1; y >= 0; y--) {
		for (int x = 0; x < ANCHO; x++) {
			printf("%c%c", marcasV[x][y], marcasH[x][y]);
		}
		printf("\n");
	}
}
```

```c
/**********************************************************
* Interfaz de módulo: Tortuga
*
* Descripción:
*   Este módulo define el tipo abstracto Tortuga
*   capaz de ir trazando una trayectoria mediante
*   avances y giros
***********************************************************/

#pragma once

typedef enum T_Rumbo { Este, Norte, Oeste, Sur };

typedef struct T_Tortuga {
	void Poner(int x, int y, T_Rumbo rumbo);
	void Avanzar();
	void GirarDerecha();
	void GirarIzquierda();

	private:
		int xx, yy;
		T_Rumbo sentido;
};
```

```c
/**********************************************************
* Interfaz de módulo: Papel
*
* Descripción:
*   Este módulo encapsula un único ejemplar de
*   dato abstracto de tipo "Papel", capaz de almacenar
*   un dibujo formado por trazos en una cuadrícula
***********************************************************/

#include "M_Tortuga.h"
#include "M_Papel.h"

void T_Tortuga::Poner(int x, int y, T_Rumbo rumbo) {
	xx = x;
	yy = y;
	sentido = rumbo;
}

void T_Tortuga::Avanzar() {
	switch (sentido) {
		case Norte:
			MarcarVetrtical(xx, yy);
			yy++;
			break;
		case Sur:
			yy--;
			MarcarVetrtical(xx, yy);
			break;
		case Este:
			MarcarHorizontal(xx, yy);
			xx++;
			break;
		case Oeste:
			xx--;
			MarcarHorizontal(xx, yy);
			break;
	}
}

void T_Tortuga::GirarDerecha() {
	sentido = T_Rumbo((int(sentido) - 1 + 4) % 4);
}

void T_Tortuga::GirarIzquierda() {
	sentido = T_Rumbo((int (sentido) + 1) % 4);
}
```

```c
/**********************************************************
* Interfaz de módulo: CurvaC
*
* Descripción:
*   Este módulo contiene la fucnion que genera la Curva-C
***********************************************************/

#include "M_CurvaC.h"

void CurvaC(int orden, T_Tortuga &t) {
	if (orden == 0) {
		t.Avanzar();
	} else if (orden > 0) {
		CurvaC(orden - 1, t);
		t.GirarDerecha();
		CurvaC(orden - 1, t);
		t.GirarIzquierda();
	}
}
```

# 15.3.4 Reutilización de módulos

Enlace: [[Fundamentos de programación.pdf#page=437&selection=168,0,182,0|Fundamentos de programación, página 437]].

La reutilización de software es siempre un gran aliado del programador, siempre y cuando las funciones y módulos creados sean lo suficientemente abstractos que se puedan aplicar al problema actual. Por ejemplo, los módulos anteriores podrían usarse para pintar otras figuras.

Los módulos que mantienen relaciones entre sí puede agruparse en una biblioteca o librería.

Por poner un ejemplo de reutilización:

```c
/*******************************************************
 * Programa: Espiral
 *
 * Descripción:
 * Este programa dibuja una figura espiral cuadrada, del
 * tamaño que se indique como dato.
 *******************************************************/

#include <stdio.h>
#include "Tortuga.h"
#include "Papel.h"

/** Avanzar N pasos */
void AvanzarN (T_Tortuga &t, T_Papel &p, int pasos) {
    for (int k = 1; k <= pasos; k++) {
        t.Avanzar(p);
    }
}

/** Programa principal */
int main() {
    int lado;
    T_Tortuga tt;
    T_Papel pp;

    printf("Tamaño: ");
    scanf("%d", &lado);
    pp.PonerEnBlanco();
    tt.Poner(0, 0, Este);
    for (int k = lado; k > 1; k--) {
        AvanzarN(tt, pp, k);
        tt.GirarIzquierda();
        AvanzarN(tt, pp, k);
        tt.GirarIzquierda();
    }
    pp.Imprimir();
}
```
