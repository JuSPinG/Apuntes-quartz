# 2.7.1 El procedimiento `printf`

Enlace: [[Fundamentos de programación.pdf#page=55&selection=591,0,597,6|Fundamentos de programación, página 55]].

Este procedimiento (función) pertenece a la librería `stdio.h` y se usa así:

```c++
printf(X);
```

Para concatenar o imprimir datos con este procedimiento, se usa el siguiente método:

```c++
printif("%d", 120); // resultado: 120
printif("Datos: %d-%d", 120, 255 / 3); // resultado: Datos: 120-85
```

El `%d` se usa para establecer el tipo de valor a imprimir, en este caso, `d`, de decimal, y se puede usar la siguiente tabla:


| Código |   Nemotécnico   |            Tipo de valor            |
| :----: | :-------------: | :---------------------------------: |
|   d    |   **d**ecimal   |               Entero                |
|   f    | **f**ixed point |                Real                 |
|   e    | **e**xponential |    Real con notación exponencial    |
|   g    |   **g**eneral   | Real con o sin notación exponencial |
|   c    |   **c**harter   |             Un carácter             |
|   s    |   **s**tring    |      Una cadena de caracteres       |
Acompañando el `%` también se puede encontrar un número que especifique cuántos caracteres tiene reservado la impresión del valor, si aparecen menos de los especificados, se colocan tantos espacios en blanco como caracteres hayan sobrado.

```c++
printf("%5d", 120 / 12); // "   10"
```

Por otro lado, cuando se representa un valor real, se puede especificar cuántos decimales se quiere que aparezca usando un método parecido:

```c++
printf("%10.3f", 1.3); // 1.300
```
