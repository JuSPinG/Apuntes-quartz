# 2.5.1 El tipo entero (*int*)

Enlace: [[Fundamentos de programación.pdf#page=46&selection=12,0,20,5|Fundamentos de programación, página 46]].

El *integer* puede obtener la siguiente lista de valores, dependiendo de cuántos bits se le dediquen.

| Tamaño  | Rango de valores                                              |
| ------- | ------------------------------------------------------------- |
| 16 bits | -32.768... 0 ... 32.768                                       |
| 32 bits | -2.147.483.648... 0 ... 2.147.483.647                         |
| 64 bits | -9.223.372.036.854.775.808... 0 ... 9.223.372.036.854.775.807 |
Esto se calcula de la siguiente manera:

$$\text{Rango}=\pm\frac{2^{\text{Número de bits}}}{2}$$

Para hacer referencia a estos límites, se puede usar el nombre simbólico `INT_MIN` e `INT_MAX`. Estas palabras se pueden encontrar en `<limits.h>`.

Cabe recalcar algunas características de los operadores, por ejemplo, el operador división, no devuelve un resultado redondeado, si no truncado con su valor más próximo a 0.

Por otro lado, si un resultado de una operación se sale del rango de valores del entero, entonces el programa devolverá un error.
# 2.5.2 El tipo real (*float*)

Enlace: [[Fundamentos de programación.pdf#page=48&selection=41,0,49,7|Fundamentos de programación, página 48]].

De coma flotante, *float*, aparece un dato que guarda un número real, pero que puede perder precisión en el proceso, este es el caso de números como $\pi$, $e$ o cualquier número que se salga del siguiente rango, que dependerá de la plataforma que usemos.

![[Tabla de precisión tipo float.png]]

Un ejemplo de la pérdida de precisión sería el siguiente:

$$10.0/3.0 = 3.3333332538604736E+0$$

Puede variar el resultado en función de la plataforma, puede, que incluso el error no aparezca en la 7ª cifra si no en una más pequeña.
# 2.5.3 El tipo carácter (*char*)

Enlace: [[Fundamentos de programación.pdf#page=48&selection=41,0,49,7|Fundamentos de programación, página 48]].

El tipo *char* no es más que un número que tiene asignado un glifo, y en vez de representar dicho número, se imprime el glifo. Hay varias tablas (*charset*) que codifican esto mismo, ya sea la ASCII, Latin-1 o UNICODE:

![[Tabla de codificaciones del char.png]]

Cada tabla superior, es una ampliación de su inferior.

Por otro lado, también se usan tablas de 8 bits, pues en lenguajes como el de C/C++, los caracteres ocupan esto mismo.

Para obtener un carácter dada la posición, en C/C++, se usa la siguiente función:

```c++
char(10); // Carácter de la posición 10, '\n'
char(13); // Carácter de la posición 13, '\r'
char(65); // Carácter de la posición 65, 'A'
```

Y se puede hacer esto mismo pero al revés:

```c++
int('A'); // 65
int('Z'); // 90
```

Cabe recalcar que la tabla ASCII cuenta con cierto orden, los caracteres de la "A" a la "Z", de la "a" la "z", y del "0" al "9" van seguidos.

En C y C± se usa la librería `ctype` para obtener la siguiente información de los caracteres, en C++ se usa `cctype`.

```c++
isalpha(X);
isascii(X);
iscntrl(X);
isdigit(X);
islower(X);
isalpha(X);
...
```
