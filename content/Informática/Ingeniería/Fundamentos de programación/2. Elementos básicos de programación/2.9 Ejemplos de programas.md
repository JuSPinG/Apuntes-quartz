# 2.9.2 Suma de números consecutivos

Enlace: [[Fundamentos de programación.pdf#page=61&selection=4,0,12,12|Fundamentos de programación, página 61]].

```c
/* Programa: 2024-11-04 */
/* Suma de números consecutivos, del 4 al 45 */

#include<stdio.h>

int main() {
  printf("La suma de los números enteros del 4 al 45 da:");
  printf("%5d", (45 - 4 + 1) * (45 + 4) / 2);
}
```
