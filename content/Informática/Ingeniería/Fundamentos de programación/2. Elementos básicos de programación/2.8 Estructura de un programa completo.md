# 2.8.2 Descripción formal de la estructura de un programa

Enlace: [[Fundamentos de programación.pdf#page=59&selection=234,0,258,7|Fundamentos de programación, página 59]].

La descripción formal de un programa es la siguiente:

$$\texttt{<Programa> ::= \{<Include>\} int main() <Bloque>}$$
$$\texttt{<Include> ::= \#include <Nombre\_modulo.h>}$$

El bloque contiene, de forma simplificada, una serie de secuencias.

$$\texttt{<Bloque> ::= \{Parte\_ejecutiva\}}$$
$$\texttt{<Parte\_ejecutiva> ::= \{Sentencia\}}$$
