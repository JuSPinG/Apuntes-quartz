# 9.2.1 Definición de tipos enumerados

Enlace: [[Fundamentos de programación.pdf#page=231&selection=8,0,16,10|Fundamentos de programación, página 231]].

En C± se pueden crear tipos de datos que están conformados de otros valores, este es el caso del tipo enumerado:

```c
typedef enum TipoDia {
  Lunes,
  Martes,
  Miercoles,
  Jueves,
  Sabado,
  Domingo
};
```

^edbf21

De esta forma, se le asigna una clave a cada valor, se establece un orden interno, y sus valores se vuelven constantes. Son como las listas de [[Python]].

Los tipos enumerados forman parte de los denominados "tipos ordinales", conformados por `int` y `char`.
# 9.2.2 Uso de tipos enumerados

Enlace: [[Fundamentos de programación.pdf#page=231&selection=448,0,456,10|Fundamentos de programación, página 231]].

Con respecto al código anterior ([[#^edbf21]]), se podría enlazar con el siguiente otro:

```c
TipoDia diaSemana;

diaSemana = Lunes;
```

Para conocer la posición que ocupa un elemento en la lista, se puede usar el operador `int` de la siguiente forma:

```c
int(Lunes) == 0
int(Miercoles) == 2
```

Y, al igual que en [[Python]], se puede hacer lo siguiente con las listas:

```c
TipoNumerado(N);
```

Donde `N` es la posición de un elemento.

Un ejemplo más funcional del uso del tipo enumerado:

```c
diaSemana = Jueves;
diaSemana = TipoDia(int(diaSemana) + 1);
mes = Marzo;
mes = TipoMes(int(mes) - 1);

/*-- Resultado --*/
diaSemana == Viernes
mes == Febrero
```

Aunque, siguiendo esta lógica, si se suma una posición al domingo, el programa devuelve un error, esto se podría calcular de la siguiente manera:

```c
TipoDia SumarDias(TipoDia Hoy, int N) {
  const int DiasSemana = 7;
  int aux;

  aux = (int(Hoy) + N) % DiasSemana;
  return TipoDia(aux);
}
```
