Los tipos `int`, `char` y `float` pueden estar muy bien, pero cuando se requiere de tratamientos más complejos, es probable que se requiera guardar información de tipo escalar (por ejemplo). El programador puede definir nuevos tipos de datos, así, cada tipo de dato adquiere un significado específico.

En C/C±/C++, el programador puede definir nuevos tipos de datos de la siguiente manera:

```c
typedef int TipoEdad;
typedef char TipoSexo;
typedef float TipoAltura;
```

Por ejemplo, este trozo de código se podría usar de la siguiente manera:

```c
TipoEdad edad1, edad2;
TipoSexo sexo;
TipoAltura altura;

edad2 = edad1 + 5;
sexo = 'V';
altura = 1.75;
```

A esto se le llama "tipo sinónimo", pues en realidad, `int` y `TipoEdad`, en ese programa, son lo mismo. Este cambio puede parecer una chorrada, pero puede traer ventajas de portabilidad debido a su nuevo nivel de abstracción.
