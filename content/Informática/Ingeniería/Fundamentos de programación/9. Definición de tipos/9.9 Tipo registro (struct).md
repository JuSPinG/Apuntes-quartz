# 9.9.1 Definición de registros

Enlace: [[Fundamentos de programación.pdf#page=249&selection=42,0,48,9|Fundamentos de programación, página 249]].

Así se define un registro en C:

```c
typedef struct TipoRegistro {
  Tipo1 Valor1;
  Tipo2 Valor2;
  Tipo3 Valor3;
  ...
}
```

Supongamos un ejemplo práctico:

```c
typedef enum TipoMes {
  Enero, Febrero, Marzo, Abril, Mayo, Junio, Julio, Agosto, Septiembre, Octubre, Noviembre, Diciembre
};
typedef struct TipoFecha {
  int dia;
  TipoMes mes;
  int anno;
};
typedef struct TipoPunto {
  float x;
  float y;
}
```

# 9.9.3 Uso de registros

Enlace: [[Fundamentos de programación.pdf#page=250&selection=231,0,239,9|Fundamentos de programación, página 250]].

Las operaciones de los registros pueden ser de tipo parcial, o de tipo completo. Depende de si se usa todo el registro o solo una parte. Lo común, es usar solo un elemento.

```c
punto2 = punto1; /* Tipo completo, solo admisible si son del mismo tipo */
```

También se pueden pasar como argumento:

```c
void LeerFecha(TipoFecha & hoy);
float Distancia(TipoPunto punto1, TipoPunto punto2);
```

Por otro lado, las operaciones parciales hacen uso de la siguiente sintaxis:

$$\texttt{registro.campo}$$

Justo igual que en JavaScript.

```c
void LeerFecha(TipoFecha & fecha) {
  int aux;

  scanf("%d", &aux);
  if ((aux > 0) && (aux <= 31)) {
    fecha.dia = aux;
  } else {
    fecha.dia = 1;
  }
  LeerMes(fecha.mes);
  scanf("%d", &aux);
  fecha.anno = aux;
}

/* Opción 1 */

float Distancia(TipoPunto p1, TipoPunto p2) {
  float dx, dy;

  dx = p2.x - p1.x;
  dy = p2.y - p1.y;
  return sqrt(dx*dx + dy*dy);
}

TipoPunto PuntoMedio(TipoPunto p1, TipoPunto p2) {
  TipoPunto m;

  m.x = (p1.x + p2.x) / 2.0;
  m.y = (p1.y + p2.y) / 2.0;
  return m;
}

TipoPunto a, b, centro;

centro = PuntoMedio(a, b);
```
