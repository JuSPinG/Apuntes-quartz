¡Por fin! *String*.

Así se define un *string*:

```c
typedef char Nombre[N];
```

Cabe recalcar que cada cadena requiere en su final un carácter nulo ("\0"). Por lo que para declarar una cadena de 20 caracteres, en el caso anterior, N debe de ser igual a 21.

```c
typedef char Cadena20[21];

Cadena20 nombre, apellido;
nombre = "Marcos"; /* Error, esto es pseudocódigo explicativo */
```

Usar *strings* es tan habitual que en C/C± se desarrolló la librería `string.h` para manejar dichos textos. He aquí algunas funciones:


|      Método      |                                                                                Descripción                                                                                 |
| :--------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| `strcpy(c1, c2)` |                                                                               Copia c2 en c1                                                                               |
| `strcar(c1, c2)` |                                                                     Concatena c2 a continuación de c1                                                                      |
|   `strlen(c1)`   |                                                                         Devuelve la longitud de c1                                                                         |
| `strcmp(c1, c2)` | Compara c1 con c2. Da 0 si son iguales, negativo si c1 tiene una carácter X menor que c2, y mayor en el caso contrario, donde X es el primer carácter desigual (en ASCII). |

Entonces, para asignar una cadena a una variable, se usa el procedimiento `strcpy`:

```c
strcpy(nombre, "Marcos");
strcpy(apellido, "Santos");
```

También se pueden usar las cadenas en argumentos en procedimientos o funciones:

```c
printf("Datos: %s - %s: %s %s\n", idioma, direccion, "Jose", apellido);
```

Y lo mismo con `scanf`.

```c
/** Programa: Cadenas */
/* Ejemplo de manejo de cadenas de caracteres */

#include <stdio.h>
#include <string.h>

typedef char TipoCadena[20];

int main() {
    TipoCadena nombre, apellido;
    typedef char TipoTexto[100];
    TipoTexto texto;
    int resul;

    printf("Nombre y Apellido? ");
    scanf("%s%s", nombre, apellido);
    printf("Datos: %s - %s \n", nombre, apellido);
    printf("Longitudes: %d %d\n", strlen(nombre), strlen(apellido));
    strcpy(texto, nombre);
    printf("Texto copiado: %s\n", texto);
    strcat(texto, apellido);
    printf("Texto concatenado: %s\n", texto);
    resul = strcmp(apellido, nombre);
    if (resul == 0) {
        printf("Nombre y Apellido iguales\n");
    } else if (resul > 0) {
        printf("%s es anterior a %s\n", nombre, apellido);
    } else {
        printf("%s es anterior a %s\n", apellido, nombre);
    }
}
```
