# 9.6.1 Declaración de vectores

Enlace: [[Fundamentos de programación.pdf#page=238&selection=175,0,193,2|Fundamentos de programación, página 238]].

La declaración del vector se hace de la siguiente forma:

```c
typedef TipoElemento TipoVector[NumeroElementos];
```

He aquí un ejemplo práctico:

```c
cont int LONGITUDCADENA = 30;

typedef enum TipoDia {
  Lunes, Martes, Miercoles, Jueves, Viernes, Sabado, Domingo
};
typedef enum TipoColor { Rojo, Amarillo, Azul };
typedef float TipoMedidas[3];
typedef TipoColor TipoPaleta[5];
typedef char TipoCadena[LONGITUDCADENA];
typedef TipoDia TipoAgenda[7];
typedef bool TipoEstados[8];
typedef int TipoVector[10];

TipoVector vector1, vector2;
TipoAgenda agendaUno, agendaDos;
```
# 9.6.2 Inicialización de un vector

Enlace: [[Fundamentos de programación.pdf#page=240&selection=0,0,6,6|Fundamentos de programación, página 240]].

```c
TipoAgenda agendaUno = {

TipoEstados estadoMotor = {
  true, false, true, true, false, false, false, true
};

```
# 9.6.3 Operaciones con elementos de vectores

Enlace: [[Fundamentos de programación.pdf#page=240&selection=267,0,277,8|Fundamentos de programación, página 240]].

Y ahora, se podrían operar los elementos de los vectores:

```c
miVector[3] = 3*vector1[0] + 2*vector2[0];
frase[13] = 'A';
estadoMotor[5] = true;
```

Importante no salirse del rango de valores posibles del índice.
# 9.6.4 Operaciones globales con vectores

Enlace: [[Fundamentos de programación.pdf#page=241&selection=417,0,425,8|Fundamentos de programación, página 241]].

Para copiar los datos de un vector a otro, se usa el siguiente método:

```c
for (int i = 0; i < NumeroElementos; i++) {
  vector2[i] = vector1[i];
}
```

Ciertamente, un poco engorroso.

# 9.6.5 Paso de argumentos de tipo vector

Enlace: [[Fundamentos de programación.pdf#page=242&selection=365,0,383,6|Fundamentos de programación, página 242]].

Al igual que se pasan argumentos simples a las funciones y métodos, se pueden pasar vectores enteros:

```c
void leerVector(TipoVector v) { ... }

LeerVector(vector1);
```

En estas ocasiones, los datos de los vectores pueden ser modificados sin necesidad de que un "&" los toque, para que no suceda, es necesario añadir un `const`:

```c
void leerVector(const TipoVector v) { ... }

LeerVector(vector1);
```
