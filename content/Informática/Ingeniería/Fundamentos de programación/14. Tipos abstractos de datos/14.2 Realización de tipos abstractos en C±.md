# 14.2.1 Definición de tipos abstractos como tipos registro (`struct`)

Enlace: [[Fundamentos de programación.pdf#page=387&selection=287,0,329,1|Fundamentos de programación, página 387]].

Así se una estructura de TAD:

```c
typedef struct T_Punto {
  float x;
  float y;

  void Leer(); /* Lee un punto con formato "(x, y)" */
  void Escribir(); /* Escribe un punto con formato "(x, y)" */
  float Distancia(T_Punto p); /* Calcula la distancia de un punto a otro */
}
```

Usemos el código:

```c
T_Punto p, q;

p.x = 3.3;
p.y = 4.4;

p.Leer();
p.escribir();
printf("%f", p.Distancia(q));
```

Solo se insertan las cabeceras de los subprogramas, para definir el bloque, se usa el operador `::`:

```c
#include<stdio.h>
#include<math.h>

/* Excepción en lectura */
typedef enum T_PuntoError { PuntoNoLeido };

/* Leer un punto con formato "(x, y)" */
void T_Punto::Leer() {
  int campos;

  campos = scanf("(%f, %f)", &x, &y);
  if (campos < 2) {
    throw PuntoNoLeido;
  }
}

/* Escribir un punto con formato "(x, y)" */
void T_Punto::Escribir() {
  printf("(%f, %f)", x, y);
}

/* Calcular la distancia de un punto a otro */
float T_Punto::Distancia(T_Punto p) {
  float deltaX, deltaY;

  deltaX = x - p.x;
  deltaY = y - p.y;
  return sqrt(deltaX*deltaX + deltaY*deltaY);
}
```
# 14.2.2 Ocultación

Enlace: [[Fundamentos de programación.pdf#page=393&selection=110,0,112,10|Fundamentos de programación, página 393]].

Introducir valores de coordenadas es simple por la razón de que no hay restricción, se puede introducir casi cualquier número, pero en cambio, si se quiere crear una estructura de tipo fecha, es necesario hacer una comprobación para no admitir entradas negativas, días por encima de 31 o meses por encima de 12. Es necesario ocultar este procedimiento, esto se hace con la palabra clave `private`.

```c
typedef struct T_Fecha {

  /* Dar valor a un dato fecha */
  void Poner(int dia, int mes, int anno);

  /* Obtener el contenido de un dato fecha */
  int Dia();
  int Mes();
  int Anno();

  private:
    int dia, mes, anno;
};
```

El problema de la ocultación es que ahora es necesario llamar a una función para obtener los datos ocultados.
