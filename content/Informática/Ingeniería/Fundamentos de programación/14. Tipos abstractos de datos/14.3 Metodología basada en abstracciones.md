# 14.3.1 Desarrollo por refinamiento basado en abstracciones

Enlace: [[Fundamentos de programación.pdf#page=400&selection=333,0,355,2|Fundamentos de programación, página 400]].

En la técnica de desarrollo descendente, ante cada operación, se puede considerar hacer una de las siguientes 3 cosas:

- Es una operación terminal, por lo que se codifica mediante sentencias del lenguaje.
- Es una operación compleja, por lo que se descompone en otras más sencillas.
- Es una operación abstracta, por lo que se escribe la cabecera y más tarde se desarrolla el bloque.

Se puede crear un paralelismo entre esta lista y la lista de la metodología basada en abstracciones:

- El dato es elemental, por lo que se usa directamente un tipo predefinido del lenguaje para representarlo.
- El dato es complejo, por lo que se descompone en otros más sencillos, ya sea usando formaciones o uniones.
- El dato es abstracto, por lo que se especifica su interfaz dejando para más adelante los detalles de su implementación.

Para ejemplificar esto, se pretende dibujar una Curva C, que se caracteriza por las siguientes normas:

- $C(0)$ es un trazo recto de longitud unidad.
- $C(n)$, donde $n > 0$, equivale a dibujar 2 veces $C(n - 1)$, con un giro de 90º a la derecha entre ambas.

![[Ejemplo Curva C.png]]

- Imprimir Curva C →
	- Iniciar la página en blanco.
	- Componer el dibujo de la curva.
	- Imprimir la página.
```c
/*-- Componer el dibujo de la curva --*/
if (el orden es 0) {
  Trazar un segmento unidad
} else if (el orden es > 0) {
  Componer la curva de orden anterior
  Girar a la derecha
  Componer la curva de orden anterior
  Girar a la izquierda
}
```

Estos pasos siguen la técnica de gráficos de tortuga empleada en el lenguaje LOGO. Si asumimos que tenemos el comportamiento de la tortuga (recordad el módulo Turtle de [[Python]]), se pueden renombrar los procesos:

- Para la tortuga →
	- Avanzar la tortuga un paso.
	- Girar a la tortuga a la derecha.
	- Girar a la tortuga a la izquierda.
- Para el papel.
	- Iniciar el papel en blanco.
	- Registrar un trazo horizontal.
	- Registrar un trazo vertical.
	- Imprimir el contenido del papel.

Con esta idea general, se pueden pensar en las abstracciones:

- Un subprograma para generar recursivamente la Curva-C de un orden dado.
- Un TAD que implemente el agente de dibujo, es decir, la tortuga.
- Un TAD que implemente el registro del dibujo, el papel.

```c
/**************************************
* Procedimiento: CurvaC
***************************************/

void CurvaC(int orden, T_Tortuga &t, T_Papel &p);

/**************************************
* Tipo abstracto: Papel
***************************************/
typedef struct T_Papel {
  void PonerEnBlanco();
  void MarcarHorizontal(int x, int y);
  void MarcarVertical(int x, int y);
  void Imprimir();

  private:
    /* Matriz con los trazos horizontales y verticales */
};

/**************************************
* Tipo abstracto: Tortuga
***************************************/
typedef enum T_Rumbo {Este, Norte, Oeste, Sur};

typedef struct T_Tortuga {
  void Poner(int x, int y, T_Rumbo rumbo);
  void Avanzar(T_Papel &p);
  void GirarDerecha();
  void GirarIzquierda();

  private:
    /* Posición y orientación de la tortuga */
}
```
