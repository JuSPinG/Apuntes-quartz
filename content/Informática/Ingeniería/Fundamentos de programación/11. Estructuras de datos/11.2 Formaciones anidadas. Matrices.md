# 11.2.2 Operaciones con matrices

Enlace: [[Fundamentos de programación.pdf#page=298&selection=100,0,106,8|Fundamentos de programación, página 298]].

```c
void EscribirMatriz(const TipoMatriz m) {
  for (int i = 0; i < NumFilas; i++) {
    for (int j = 0; j < NumColumnas; j++) {
      printf("%10d", m[i][j]);
    }
    printf("\n");
  }
}
```

Así es como se indexa una matriz, un poco tedioso y bastante costoso de recursos.

Aunque, al igual que cuando se indexa una tabla en bases de datos, se puede imprimir una fila directamente:

```c
void EscribirFila(const TipoFila f) {
  for (int i = 0; i < NumColumnas; i++) {
    printf("%10d", f[i]);
  }
  printf("\n");
}

void EscribirMatriz(const TipoMatriz m) {
  for (int i = 0; i < NumFilas; i++) {
    EscribirFilas(m[i]);
  }
}
```

Desafortunadamente, las matrices de tipo abiertas no se pueden usar en C/C±/C++, pero se puede hacer un pequeño apaño, definiendo la matriz como vector de vectores:

```c
void EscribirFila(const TipoElemento f[], int columnas) {
  for (int i = 0; i < columnas; i++) {
    printf("%10d", f[i]);
  }
  printf("\n");
}

void EscribirMatriz(const TipoFIla m[]) {
  for (int i = 0; i < NumFilas; i++) {
    EscribirFila(m[i], NumColumnas);
  }
}
```
# 11.2.3 Ejemplo: Contrastar una imagen

Enlace: [[Fundamentos de programación.pdf#page=300&selection=12,0,20,6|Fundamentos de programación, página 300]].

Supongamos una imagen monocromática con valores de gris del 0 al 5. Este programa se centra en cambiar dichos valores al 0 o 1.

```c
/*****************************************
* Programa: Contrastar
*
* Descripción:
*   Este programa convierte una imagen digitalizada
*   a niveles de blanco y negro puros
******************************************/

#include<stdio.h>

const int ANCHO = 40;
const int ALTO = 20;
const int BLANCO = 0;
const int NEGRO = 5;

typedef int Imagen_t[ALTO][ANCHO];

/* Leer la imagen */
void LeerImagen(Imagen_t imagen) {
  char c;

  for (int i = 0; i < ALTO; i++) {
    for (int j = 0; j < ANCHO; j++) {
      scanf(" %c", &c);
      imagen[i][j] = int(c) - int('0');
    }
  }
}

/* Contrastar la imagen */
void Contrastar(Imagen_t imagen, int nivel) {
  for (int i = 0; i < ALTO; i++) {
    for (int j = 0; j < ANCHO; j++) {
      if (imagen[i][j] <= nivel) {
        imagen[i][j] = BLANCO;
      } else {
        imagen[i][j] = NEGRO;
      }
    }
  }
}

/* Imprimir la imagen */
void Imprimir(const Imagen_t imagen) {
  const char PUNTO[6] = {' ', '*', '+', 'x', 'X', '#'};

  for (int i = 0; i < ALTO; i++) {
    for (int j = 0; j < ANCHO; j++) {
      printf("%c", PUNTO[imagen[i][j]]);
    }
    printf("\n");
  }
}

/* Programa principal */
int main() {
  Imagen_t imagen;

  LeerImagen(imagen);
  printf("Imagen inicial: \n");
  Imprimir(imagen);

  Contrastar(imagen, 3);
  printf("\nImagen contrastada: \n");
  Imprimir(imagen);
}
```
