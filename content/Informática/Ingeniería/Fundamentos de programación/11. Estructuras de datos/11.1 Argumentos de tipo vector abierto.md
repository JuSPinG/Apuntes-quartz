Cuando se usan vectores en procedimientos o funciones, puede ser molesto tener que multiplicar el código de la función para tener uno para cada caso en el que el vector sea distintos. Por ello, se pueden usar vectores abiertos:

```c
void EscribirVectorAbierto(const int v[], int numElementos) {
  for (int i = 0; i < numElementos; i++) {
    printf("%10d", v[i]);
  }
  printf("\n");
}
```

# 11.1.1 Ejemplo: Contar letras y dígitos

```c
/**********************************************
* Programa: Contral letras y dígitos
*
* Descripción:
*   Cuenta las letras y dígitos en un texto
*   que proporciona el usuario
***********************************************/

#include<stdio.h>
#include<ctype.h>

int main() {

  int letras = 0;
  int digitos = 0;
  int blancos = 0;
  
  char respuesta[50] = "Estamos en el mes 12";
  pos = 0;


  printf("Bienvenido al programa que cuenta letras y digitos, ingresa un texto: ");
  /* scanf("%c", respuesta); //Medio inviable */

  while (respuesta[pos] != '\0') {
  
    if (isalpha(respuesta[pos])) {
      letras++;
    } else if (isdigit(respuesta[pos])) {
      digitos++;      
    } else if (isspace(respuesta[pos])) {
      blancos++;
    }
    pos++;
  }
  printf("========Resumen========");
  printf("---Letras: %d");
  printf("---Digitos: %d");
  printf("---Espacios en blanco: %d");
}

```
