# 6.1.1 Esquema de selección

Enlace: [[Fundamentos de programación.pdf#page=130&selection=4,0,16,1|Fundamentos de programación, página 130]].

Un esquema de selección consiste en plantear una acción compuesta como la realización entre varias posibles. Es decir, discernir.

1. Identificar cada una de las alternativas del esquema, y las acciones correspondientes.
2. Identificar las condiciones para seleccionar una alternativa u otra.

Por ejemplo, una variable puede obtener un valor, pero también puede obtener otro. He aquí una materialización de lo explicado:

```c
if (anno % 4 == 0) {
  dias = 29;
} else {
  dias = 28;
}
```

O también, se podría replantear de la siguiente manera:

```c
int dias = 28;

if (anno % 4 == 0) {
  dias = 29;
}
```
# 6.1.2 Esquema de iteración

Enlace: [[Fundamentos de programación.pdf#page=131&selection=278,0,286,9|Fundamentos de programación, página 131]].

En líneas generales, se podría proceder de la siguiente manera:

1. Identificar las acciones que se van a repetir, y las variables que se necesitan usar.
2. Identificar que información se necesita actualizar en cada iteración, y la información que se va a pasar a la siguiente iteración.
3. Identificar cuándo va a terminar el bucle.
4. Identificar los valores iniciales de las variables, y declararlos fuera del bucle.

Otro ejemplo: Se pretende imprimir la serie de Fibonacci.

1. Acciones útiles a repetir y variables necesarias:
	1. Imprimir un término.
		1. `printf("%10d\n", termino);` 
	2. El término a imprimir.
		1. `int termino;`
2. Actualizar las variables de una iteración a la siguiente:
	1. Calcular el termino actual en función de los dos anteriores.
		1. `aux = termino + anterior;`
		2. `anterior = termino;`
		3. `termino = aux;`
	2. Variables adicionales.
		1. `int anterior;`
		2. `int aux;`
3. Condición de terminación:
	1. Para que el código no produzca un *overflow*, se requiere de la introducción de la parada.
		1. `INT_MAX - termino < anterior`
4. Valores iniciales de las variables, declarados fuera:
	1. `anterior = 0;`
	2. `termino = 1;`

Quedando en total:

```c
int termino = 1;
int anterior = 0;
int aux;

while (INT_MAX - termino >= anterior) {
  aux = termino + anterior;
  anterior = termino;
  termino = aux;
  printf("%10d\n", termino);
}
```
