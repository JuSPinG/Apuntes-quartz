# 6.2.1 Ejemplo: Imprimir el contorno de un triángulo

Enlace: [[Fundamentos de programación.pdf#page=133&selection=278,0,294,9|Fundamentos de programación, página 133]].

Se busca dicha salida:

![[Ejemplo contorno triángulo equilátero.png]]

- Planteamiento: Imprimir el borde de un triángulo →
	- Imprimir el vértice superior →
		- Imprimir N-1 espacios en blanco: `for (int k = 1; k <= N-1; k++) { printf(""); }`
		- Imprimir un asterisco: `printf("*");`
		- Saltar a la línea siguiente: `printf("\n");`
	- Imprimir los bordes laterales (línea *k*) →
		- Imprimir N-k espacios blancos.
		- Imprimir un asterisco.
		- Imprimir 2k-3 espacios blancos.
		- Imprimir un asterisco.
		- Saltar a la siguiente línea.
	- Imprimir el borde inferior.

## Mi propuesta

```c
/****************************************************************************
* Programa: Pirámide-asteriscos
*
* Descripción:
*   El programa imprime una serie de asteríscos formando una pirámide
*   equilátera, la altura es introducida por el usuario
*****************************************************************************/

#include<stdio.h>

int main() {

  int lado;

  printf("Cuanto quieres que mida el triangulo?: ");
  scanf("%d", &lado);

  lado = lado - 2; /* Corrección para solucionar aumentos de lado innecesarios */

  /*-- Bucle para la punta del triángulo --*/
  for (int i = lado+1; i >= 0; i--) {
    printf(" ");
  }
  printf("*\n");

  /*-- Bucle principal, donde se imprimen la mayoría de partes de lado --*/
  for (int i = lado; i >= 0; i--) {

    for (int j = i; j >= 0; j--) {
      printf(" ");
    }
    printf("*");

    for (int j = (lado-i)*2; j >= 0; j--) {
      printf(" ");
    }
    printf("*\n");
  }

  /*-- Bucle final para el cierre del lado inferior --*/
  for (int i = (lado+2)*2; i >= 0; i--) {
    printf("*");
  }
}
```

## Las propuestas

```c
/*****************************************************
* Programa: Triangulo (Versión inicial)
*
* Descripción:
*   Este programa escribe el borde de un triángulo
*   aproximadamente equilátero, usando asteriscos.
******************************************************/

#include <stdio.h>

int main() {
  const int N = 7;  /* altura del triángulo */

  /*-- Escribir el vértice superior --*/
  for (int k = 1; k <= N - 1; k++) {
    printf(" ");
  }
  printf("*\n");

  /*-- Imprimir los bordes laterales --*/
  for (int k = 2; k <= N - 1; k++) {
    for (int j = 1; j <= N - k; j++) {
      printf(" ");
    }
    printf("*");

    for (int j = 1; j <= 2 * k - 3; j++) {
      printf(" ");
    }
    printf("*\n");
  }

  /*-- Imprimir el borde inferior --*/
  printf("*");
  for (int k = 1; k <= N - 1; k++) {
    printf(" *");
  }
  printf("\n");
}
```

```c
/******************************************************
* Programa: Triangulo2 (Versión corregida)
*
* Descripción:
*   Este programa escribe el borde de un triángulo
*   aproximadamente equilátero, usando asteriscos.
*   La altura del triángulo, en líneas de texto,
*   se lee como dato.
*******************************************************/

#include <stdio.h>

int main() {
  int altura;  /* altura del triángulo */

  /*-- Leer altura deseada --*/
  printf("Altura? ");
  scanf("%d", &altura);

  /*-- Imprimir el vértice superior --*/
  if (altura > 0) {
    for (int k = 1; k <= altura - 1; k++) {
      printf(" ");
    }
    printf("*\n");
  }

  /*-- Imprimir los bordes laterales --*/
  for (int k = 2; k <= altura - 1; k++) {
    for (int j = 1; j <= altura - k; j++) {
      printf(" ");
    }
    printf("*");

    for (int j = 1; j <= 2 * k - 3; j++) {
      printf(" ");
    }
    printf("*\n");
  }

  /*-- Imprimir el borde inferior --*/
  if (altura > 1) {
    printf("*");
    for (int k = 1; k <= altura - 1; k++) {
      printf(" *");
    }
    printf("\n");
  }
}
```
