# 7.2.1 Definición de funciones

Enlace: [[Fundamentos de programación.pdf#page=164&selection=397,0,403,9|Fundamentos de programación, página 164]].

Así se define la función en C±:

```c
TipoResultado NombreFuncion(Tipo1 argumento1, Tipo2 argumento2, ...) { Bloque }
```

Un ejemplo:

```c
float Potencia(float x, int n) {
  float p = 1.0;

  for (int k = 1; k <= n; k++) {
    p = p * x;
  }
  return p;
}
```

Es importante recalcar que la función acaba cuando aparece la sentencia `return`.
# 7.2.2 Uso de funciones

Enlace: [[Fundamentos de programación.pdf#page=166&selection=299,0,305,9|Fundamentos de programación, página 166]].

Es importante discernir entre argumentos reales y formales, y qué mejor forma de hacer que con un ejemplo:

```c
int FuncionMolona(int x, int y) { ... } /* x e y son argumentos formales */

FuncionMolona(a, b); /* a y b son argumentos reales */
```
