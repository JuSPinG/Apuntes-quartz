# 7.4.1 Paso de argumentos por valor

Enlace: [[Fundamentos de programación.pdf#page=172&selection=355,0,367,5|Fundamentos de programación, página 172]].

Básicamente, los argumentos de entrada a una función no pueden ser modificados por la ejecución. El clásico de toda la vida:

```c
float Distancia(float x1, float y1, float x2, float y2) {
  x1 = x2 - x1;
  y1 = y2 - y1;
  return sqrt(x1*x1 + y1*y1);
}
distanciaAB = Distancia(xA, yA, xB, yB);
```

No se modifican las variables externas `xA` e `yA`, mantienen los valores de antes de entrar a la función.
# 7.4.2 Paso de argumentos por referencia

Enlace: [[Fundamentos de programación.pdf#page=173&selection=356,0,367,10|Fundamentos de programación, página 173]].

A veces, es necesario que una función modifique el valor la variable usada como argumento. Esto se consigue usando un et  `&`.

```c
void OrdenarDos(int & y, int & z) {
  int aux;

  if (y > z) {
    y += z;
    z = y - z;
    y = y - z;
  }
}

void LeerCoordenadas(char Punto, float & x, float & y) {
  prinf("Punto %c\n", Punto);
  printf("¿Coordenada X?");
  scanf("%f", &x);
  printf("¿Coordenada Y?");
  scanf("%f", &y);
  printf("\n");
}
```
