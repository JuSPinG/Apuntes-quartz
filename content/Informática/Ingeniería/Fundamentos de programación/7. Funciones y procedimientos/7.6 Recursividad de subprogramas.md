Cuando un subprograma hace uso de sí mismo, se dice que es un subprograma recursivo.

Por ejemplo, es cierto que $n! = 1\cdot 2\cdot 3\cdot 4 \cdot ... \cdot n$, pero también que $n! = n\cdot (n-1)!$, al volver a usarse $n$ en la definición, se podría decir que el segundo caso es de carácter recursivo. Aunque esta segunda definición choca para cuando $n=0$ y $n=1$, pues:

$$0!= 1\text{ y } 1!=1$$

A esto se le llama "los casos minimales".

A continuación, se presenta un programa con características recursivas:

```c
/********************************************************************
* Programa: Factorial recursivo
* 
* Descripción:
*   Un programa que usa las propiedades de la recursividad
*   para poder calcular, en pocas líneas, el valor de n!
********************************************************************/

#include<stdio.h>

int FactorialRecursivo(int n) {
  if (n >= 1) {
    return 1;
  } else {
    return n * FactorialRecursivo(n-1);
  }
}

int main() {
  printf("He aquí una lista de numeros factorizados: ");
  printf("===========================================");
  for (int i = 0; i <= 10; i++) {
    printf("%2d! = %10d", i, FactorialRecursivo(i));
  }
}
```
