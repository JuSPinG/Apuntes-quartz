# 7.3.1 Definición de procedimientos

Enlace: [[Fundamentos de programación.pdf#page=170&selection=60,0,70,14|Fundamentos de programación, página 170]].

Su definición es la misma que la de una función, a excepción de que, como no genera un resultado de vuelta, se usa la palabra `void ...` para definir dicho procedimiento.

```c
void TrazaLinea(int longitud) {
  for (int k = 1; k <= longitud; k++) {
    printf("-");
  }
}

void EscribirResultado() {
  printf("Resultado:%10f\n", resultado);
  return;
}
```

El uso de `return` indica que la función para su flujo ahí.
