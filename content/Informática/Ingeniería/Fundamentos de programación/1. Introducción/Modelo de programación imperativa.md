Esto guarda un poco de relación con la máquina de *Von Neumann* dada en [[Implantación de sistemas operativos|ISO]].

En la programación imperativa, se crea una lista de órdenes (programa) que más tarde se le dará a un computador para que realice una tarea o más tareas. Dicho nombre, el de programación imperativa, refiere a las órdenes que se mandan ejecutar.

Mediante estructuras de control de flujo, se pueden omitir la ejecución de algunas partes del código. También, cuenta con el uso de variables, donde se asigna una información que se guarda en la RAM, a un nombre dado.

Las instrucciones típicas de un programa imperativo, consisten en obtener un resultado parcial mediante un cálculo elemental: a esto se le llama asignación.

```python
a = 34 * 5
b = 8 * 7
c = a + b
```
