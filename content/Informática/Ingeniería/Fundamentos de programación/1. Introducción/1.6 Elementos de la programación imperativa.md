# 1.6.1 Procesador, entorno, acciones

Enlace: [[Fundamentos de programación.pdf#page=33&selection=402,0,412,8|Fundamentos de programación, página 33]].

El procesador es el agente capaz de entender las órdenes del programa y ejecutarlas. El procesador debe de controlar los recursos del hardware para poder ejecutar dichas órdenes, a esto se le llama "entorno".

Las acciones son las instrucciones que el procesador lleva a cabo.

# 1.6.2 Acciones primitivas. Acciones compuestas

Enlace: [[Fundamentos de programación.pdf#page=34&selection=298,0,316,5|Fundamentos de programación, página 34]].

Las acciones que pueden ser **directamente** realizables por el procesador, se denominan como *acciones primitivas*. Esto guarda bastante relación con los lenguajes de muy bajo nivel. Entender dichas acciones es bastante complicado, esto se debe a que es lenguaje máquina.

El planteamiento razonable de un programa complejo debe pasar por usar la idea de abstracción. Antes de escribir un programa, es necesario dividir este en partes más sencillas y realizables, hasta llegar a las acciones primitivas, que son las que el procesador puede ejecutar.

Las acciones compuestas se componen de varias primitivas, cuando se requiere, por ejemplo, abrir un archivo de texto para escribir en él (acción compuesta), podemos dividir este proceso:

- Preparamos el texto a escribir.
- Ubicamos el archivo.
- Lo abrimos usando los permisos de escritura.
- Escribimos el texto.
- Guardamos el archivo.
- Lo cerramos.
