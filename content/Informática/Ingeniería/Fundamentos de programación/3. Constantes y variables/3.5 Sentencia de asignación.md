# 3.5.2 Compatibilidad de tipos

Enlace: [[Fundamentos de programación.pdf#page=74&selection=292,0,298,5|Fundamentos de programación, página 74]].

C± es un lenguaje débilmente tipado, es decir, se puede realizar una conversión de un tipo de dato a otro, pero no es dinámico, como podría ser el caso de [[Python]]. De acuerdo al *Manual de Estilo*, aunque se pueda dar una conversión automática, es necesario dejarla explícita:

```c
int saldo;
float gastos;

saldo = int(gastos);
```

Cuando un dato no se está usando, inmediatamente se desconoce su valor, esto recuerda un poco a la física cuántica, donde algo no se sabe, hasta que se interacciona con ese algo. Si una variable se deja de usar y se redefine, desde su última interacción se habrá perdido el valor que se hallaba en su posición de memoria.
