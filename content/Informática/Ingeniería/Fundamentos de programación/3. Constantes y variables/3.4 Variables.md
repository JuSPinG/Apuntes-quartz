# 3.4.1 Concepto de variable

Enlace: [[Fundamentos de programación.pdf#page=68&selection=297,0,305,8|Fundamentos de programación, página 68]].

La variable representa un valor indefinido, pero fijo, justo igual que cuando se evalúa una ecuación.

Las variables se guardan en la memoria volátil, y se usan tantas veces como se necesite. A diferencia que las constantes [[3.3 Constantes|Constantes]], las variables, como bien indica su nombre, si pueden variar de valor.

Por lo tanto, la variable solo es un pequeño espacio en la memoria, una dirección cuyo contenido puede ir variando.
# 3.4.2 Declaración de variables

Enlace: [[Fundamentos de programación.pdf#page=70&selection=130,0,136,9|Fundamentos de programación, página 70]].

Si una variable nace `int`, muere `int`, en ningún momento podría cambiar a `float`. Y se declaran antes del programa para poder utilizarse. Ejemplo:

```c
int dia, mes, anno;
```

# 3.4.3 Uso de variables. Inicialización

Enlace: [[Fundamentos de programación.pdf#page=71&selection=6,0,20,14|Fundamentos de programación, página 71]].

Inicializar una variable consiste en darle un valor definido cualquiera por primera vez. Normalmente, si solo se requiere su inicialización, vale con asignarle un valor «estándar»:

```c
float gastos = 0.0;
char modelo = '?';
```
