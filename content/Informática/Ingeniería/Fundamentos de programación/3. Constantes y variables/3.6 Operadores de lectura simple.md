# 3.6.1 El procedimiento `scanf`

Enlace: [[Fundamentos de programación.pdf#page=77&selection=10,0,18,5|Fundamentos de programación, página 77]].

El procedimiento `scanf` es sacado de la librería `stdio.h`, y se usa para leer datos de entrada y almacenarlos en variables.

```c
printf("Cuanta edad tienes?: ");
scanf("%d", &edad);
```

A continuación, se lee lo siguiente que el usuario escriba en el ordenador. En el caso de haber varias cadenas (`scanf("%d %d %s %f", );`), habrá que separar los datos por espacios, esto sucede en el caso numérico.

Por otra parte, si se intenta leer un dato de tipo `char` ("%c"), se lee inmediatamente el primer carácter que se introduzca.

La entrada de datos numéricos se puede manejar en los siguientes casos:


|  Datos  | Formato | Dato leído |
| :-----: | :-----: | :--------: |
| 12345xx |   %d    |   12345    |
| 12345xx |   %3d   |    123     |
| 12xx345 |   %3d   |     12     |
