# 10.3.1 Selección por casos

Enlace: [[Fundamentos de programación.pdf#page=272&selection=532,0,540,5|Fundamentos de programación, página 272]].

En C/C±/C++ es lo mismo escribir:

```c
switch (Expresión) {
  case v1:
    Sentencia1;
    break;
  case v2;
  case v3;
  case v4;
    Sentencia234;
    break;
  case v5;
  case v6;
    Sentencia56;
    break;
  ...
  default:
    SentenciaFinal;
}
```

Que:

```c
valor = Expresion;
if (valor == v1) {
  Sentencia1
} else if ((valor == v2) || (valor == v3) || (valor == v4)) {
  Sentencia234;
} else if ((valor == v5) || (valor == v6)) {
  Sentencia56;
}
...
else {
  SentenciaFinal;
}
```
# 10.3.2 Bucle con contador

Enlace: [[Fundamentos de programación.pdf#page=273&selection=223,0,229,8|Fundamentos de programación, página 273]].

En C/C±/C++ es lo mismo escribir:

```c
for (int indice = Inicial; indice <= Final; indice++) {
  Sentencias;
}
```

Que:

```c
int indice = Inicia;

while (indice <= Final) {
  Sentencias;
  indice;
}
```
# 10.3.3 Repetición

Enlace: [[Fundamentos de programación.pdf#page=274&selection=76,0,84,6|Fundamentos de programación, página 274]].

En C/C±/C++ es lo mismo escribir:

```c
do {
  Sentencias;
} while (Condición);
```

Que:

```c
seguir = true;

while (seguir) {
  Sentencias;
  seguir = Condición;
}
```
