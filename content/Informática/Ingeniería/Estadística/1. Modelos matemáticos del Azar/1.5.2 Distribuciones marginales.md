Se pueden establecer condiciones previas a la hora de evaluar el experimento. Por ejemplo, podemos establecer que $P(X=i)$, donde la condición impuesta a las variables es que $X$ toma el valor $i$, mientras que $Y$ queda libre:

$$P(X=i)=\sum_{j\in Y(\Omega)}P(X=i, Y=j), \ \ \ i\in X(\Omega)$$

Establecer esta condición genera un vector que en realidad es unidimensional, la variable misma. Por otro lado, si estamos ante una [[1.5.1 Distribución conjunta de un vector aleatorio|Distribución conjunta de un vector aleatorio]], entonces, poseemos una estructura bidimensional. Es interesante el uso de una tabla para plasmar esto.
# Ejemplo

Consideramos un vector aleatorio $(X, Y)$ cuya distribución conjunta está dada por la siguiente tabla:


|       |       $Y=0$       |        $Y=1$        |       $Y=2$        |                     |
| :---: | :---------------: | :-----------------: | :----------------: | :-----------------: |
| $X=0$ |       $1/6$       |        $1/6$        |       $1/6$        | $\color{blue} 3/6$  |
| $X=1$ |        $0$        |         $0$         |       $1/6$        | $\color{green} 1/6$ |
| $X=2$ |       $1/6$       |         $0$         |       $1/6$        |  $\color{red} 2/6$  |
|       | $\color{red} 2/6$ | $\color{green} 1/6$ | $\color{blue} 3/6$ |                     |
^5a5ff6

La distribución marginal de $Y$ equivale a $2/6, 1/6, 3/6$, el mismo proceso se aplica a la $X$.
