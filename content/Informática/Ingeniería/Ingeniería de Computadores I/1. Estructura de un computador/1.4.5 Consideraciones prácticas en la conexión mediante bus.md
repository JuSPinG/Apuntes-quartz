El uso de un bus compartido (por la CPU, la memoria y E/S), requiere de unos circuitos de acoplo para garantizar el correcto funcionamiento. Normalmente, cada línea de bus se conecta con un número alto de módulos, por lo que surgen los problemas de _fan out_. El _fan out_ especifica la cantidad de conexiones que se puede llegar a tener sin generar anomalías. Se suelen usar unos _drivers_ para mantener la señal activa dentro del bus, como una especie de repetidor. Estos _drivers_ se realizan con un tipo de puerta lógica especial: el triestado.

# Puertas triestado

Las puertas triestado admiten 3 estados diferentes. Estas, requieren de 2 entradas: "A" de dato, "C" de control, y una salida "Y". Cuando "C" está activa, entonces, se compara con "A", y si son equivalentes (ambos "1"), entonces, "Y" es verdadero. El término "triestado" es perfecto para explicar que, cuando "C" está desconectado, entonces, "Y" es nulo (que no 0, sencillamente deja de ser medible).
