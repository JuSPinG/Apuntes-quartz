En el comienzo de cada ciclo de instrucción, la CPU busca en memoria dicha instrucción. Esta acción dispone de un registro especial llamado "contador de programa", y se usa para llevar un control de las posiciones de memoria. A menos que se indique lo contrario, este contador siempre incrementa, buscando así de manera secuencial cada instrucción.

![[Diagrama de flujo básico en un ordenador.png]]

Este es el diagrama de flujo básico de cada operación.

La instrucción leída se almacena como un registro de instrucción, que está codificada en binario, para más tarde ser ejecutada. Las acciones se dividen en estos 4 grupos elementales:

- _CPU-Memoria_: Los datos se transfieren desde la CPU a la memoria o viceversa.
- _CPU-E/S_: Los datos se transfieren desde el mundo exterior mediante el módulo E/S.
- _Procesamiento de los datos_: La CPU opera los datos.
- _Control_: La CPU especifica una alteración en la secuencia de ejecución. Por ejemplo, tras leer la instrucción $\#234$, esta expresa la necesidad de leer la instrucción $\#315$.
