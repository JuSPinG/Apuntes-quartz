La organización interna de la matriz permite organizar capsulas de 64, 256 kilobits, 4, 8, 16, 32 o incluso 64 megabits.

Cómo organizar las celdas anteriores puede afectar al rendimiento. Hay 2 organizaciones conocidas: 2D y 21/2D.

# Organización 2D

También conocida como organización por palabras u organización lineal.

![[Organización 2D de memoria de semiconductor.png]]

Este sistema ya nos lo conocemos ([vídeo explicativo](https://youtu.be/OZCEHXlHY4E?t=345)), por lo que no merece mucha explicación.

Cuando más cuadrada la memoria, más sencillo se hace guardar información.

# Organización 21/2D

La organización 2D posee 2 problemas para la creación de módulos de memoria RAM:

1. Las $m$ puertas lógicas OR tienen demasiadas entradas ($2^n$ cada una).
2. El decodificador de direcciones es complejo y costoso.

Esto es lo que se vio en [[Memorias RAM.pdf#page=10&selection=0,0,0,3|Memorias RAM, página 10]]. Consiste en el apilado de varias matrices para poder seleccionar varios datos a la vez. Básicamente, es como si se usasen matrices tridimensionales.

![[Organización 21-2D memoria.png]]

Añadir una dimensión extra requiere que la dirección se parta en 2 para poder satisfacer 2 decodificadores.
