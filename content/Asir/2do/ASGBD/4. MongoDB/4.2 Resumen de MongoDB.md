# Explicación de MongoDB

MongoDB es una base de datos que se caracteriza por ser **NoSQL**, es decir, la típica jerarquía que se usa en SQL donde hay bases de datos, dentro de esas bases hay tablas de estructura fija, y dentro de esas tablas hay datos muy específicos. Las tablas en este sistema no son mutables en tiempo de ejecución, ni admiten tipos de datos débiles. Las referencias son la opción más seria a la hora de hacer listas de datos. Todo esto es muy distinto en NoSQL.

En cambio, el formato JSON es el que se usa típicamente para gestionar los datos. Y con JavaScript podemos añadir lógica a los datos, así como realizar las operaciones básicas. Estas propiedades le permiten romper con la jerarquía de SQL, permitiendo un escalado más horizontal, donde la creación de nuevos datos apenas depende de lo que se haya hecho hasta entonces.

Por otro lado, MongoDB se ha especializado en el acceso simultáneo y la concurrencia, pues permite un despliegue muy sencillo desde Docker.

# Manejando la base de datos

## Frutas

Para crear una tabla, la forma más normal de hacerlo es introduciendo directamente los datos. Los tipos de datos se infieren de los datos introducidos. Desafortunadamente, no existen métodos abreviados para añadir cierta lógica a las tablas, por lo que tendremos que implementarla con JavaScript.

```js
function autoincrement(sequenceName) {
	var sequenceDocument = db.contadores.findOneAndUpdate(
		{ _id: sequenceName },
		{ $inc: { seq: 1 } },
		{
			returnNewDocument: true,
			upsert: true
		}
	);
	return sequenceDocument.seq;
}
```

**Mandarinas:**
```js
db.mandarinas.insertOne({
	_id: autoincrement("id_mandarinas"),
	color: "Naranja",
	ciudad: 24,
	fecha_recogida: 2020-04-01
})
```

**Melocotones:**
```js
db.melocotones.insertOne({
	_id: autoincrement("id_melocoton"),
	tipo: "Grande y jugoso",
	suavidad: 1
})
```

**Caquis:**
```js
db.caquis.insertOne({
	_id: autoincrement("id_caquis"),
	color: "Naranja",
	pendunculo: 0,
	tiempo_maduracion: 6
})
```

**Cesta:**
```js
db.cesta.insertOne({
	_id: autoincrement("id_cesta"),
	id_mandarina: 1,
	id_melocotones: 1,
	id_caquis: 1
})
```

En el enunciado original, la colección "cesta" no existe, pues es directamente la colección "caqui" la que depende de la mandarina y el melocotón. Si se hiciese algo así, se vería de la siguiente manera:

```js
db.caquis.insertOne({
	_id: autoincrement("id_caquis"),
	color: "Naranja",
	pendunculo: 0,
	tiempo_maduracion: 6,
	id_mandarina: 1,
	id_melocotones: 1
})
```

En teoría, es esta sentencia la que debería de devolver el nombre, pero no lo he conseguido. Al parecer, existe una forma mejor con la que se puede hacer esta consulta en la que se entra en varias colecciones. Esta es la forma correcta e idiomática:

Con variables:

```js
// 1. Obtener IDs de los productos "Mouse"
const productIds = db.products.find({ name: "Mouse" }).map(p => p._id).toArray();

// 2. Obtener IDs de las órdenes que tienen esos productos
const orderIds = db.order_products.find({ product_id: { $in: productIds } }).map(op => op.orderIds).toArray();

// 3. Obtener IDs de los usuarios de esas órdenes
const userIds = db.orders.find({ _id: { $in: orderIds } }).map(o => o.user_id).toArray();

// 4. Finalmente, obtener los nombres de los usuarios
const result = db.users.find({ _id: { $in: userIds } }, { name: 1 }).toArray();

printjson(result);
```

Con _joins_:

```js
db.products.aggregate([
	// 1. Buscamos el producto "Mouse"
	{ $match: { name: "Mouse" } },

	// 2. Unimos con order_products usando el _id del producto
	{
		$lookup: {
			from: "order_products",
			localField: "_id",
			foreignField: "product_id",
			as: "items"
	    }
	},
	{ $unwind: "$items" },

	// 3. Unimos con la colección de orders
	{
		$lookup: {
			from: "orders",
			localField: "items.order_id",
			foreignField: "_id",
			as: "order_details"
		}
	},
	{ $unwind: "$order_details" },
	
	// 4. Unimos con la colección de users
	{
		$lookup: {
			from: "users",
			localField: "order_details.user_id",
			foreignField: "_id",
			as: "user"
		}
	},
  { $unwind: "$user" },

  // 5. Proyectamos solo el nombre del usuario
  { $project: { _id: 0, userName: "$user.name" } }
])
```

**Agrupar los pedidos por usuario y calcular el total gastado por cada uno:**
```js
const resultados = db.users.find().map(usuario => { const total = db.orders.find({ user_id: usuario._id }).map(pedido => pedido.total).reduce((acc, val) => acc + val, 0);
	return { nombre: usuario.name, totalGastado: total };

printjson(resultados);
```

**Listar productos únicos comprados en todos los pedidos:**
```js
db.order_products.aggregate([
	{
		$group: { _id: "$product_id" }
	},
	{
		$lookup: {
			from: "products",
			localField: "_id",
			foreignField: "_id",
			as: "detalle"
	    }
	},
	{ $unwind: "$detalle" },
	{
		$project: { _id: 0, producto: "$detalle.name" }
	}
])
```
