# [PHP Intelephense](https://marketplace.visualstudio.com/items?itemName=bmewburn.vscode-intelephense-client)

Esta extensión es sumamente importante para VSC, tanto es así, que si no la instalamos no podremos usar dicho lenguaje en el editor. También, según tengo entendido, será necesario instalar esta extensión junto con [PHP Server](https://marketplace.visualstudio.com/items?itemName=brapifra.phpserver), junto con un intérprete de PHP, claro, ya sea XAMPP o WampServer. La extensión maneja procesos internos, por lo que es difícil mostrar una captura de pantalla, sobre todo si no se instala PHP.

# [PHP Snippets](https://marketplace.visualstudio.com/items?itemName=vsc-snippets.vsc-php-snippets)

Ayuda a autocompletar bloques de código de PHP, lo que ayuda a escribir código más rápidamente. Todo lenguaje tiene sus _snippets_, y siempre viene bien tener unos instalados.
