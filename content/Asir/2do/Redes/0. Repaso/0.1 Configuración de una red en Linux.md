# Comandos para la configuración

1. **Mediante `systemctl—`**.
	1. `systemctl disable networking`: Desactiva el servicio de `networking`, normalmente, para poder utilizar la configuración de `systemd-networkd`. Cuando se ejecuta, es probable que sea necesario reiniciar el equipo.
	2. **Para `—systemd-networkd`**.
		1. `systemctl enable systemd-networkd`: Activa la configuración del servicio de configuración. Es necesario deshabilitar primer `networking` para no causar colisiones.
		2. `systemctl restart systemd-networkd`: Carga la nueva configuración de de los archivos de `systemd-networkd`.
		3. `systemctl status systemd-networkd`: Comprueba si las reglas de `systemd-neworkd` se aplican correctamente.
2. `networkctl`: Comprueba el estado de las interfaces. Si aparece que están `unmanaged`, entonces, necesitan ser configuradas mediante un archivo en `/etc/systemd/network`. Si aparece que está `configuring`, entonces, será necesario ejecutar el comando 1.2.1 y 1.2.2.
3. **Mediante `ip—`**.
	1. `ip a`: También conocido como `ip address list`, muestra información de todas las interfaces y de sus direcciones IP.
	2. `ip link set {nombre de interfaz} down/up`: Permite levantar o tumbar cualquier interfaz.
	3. `ip addr add {IP} dev {nombre de interfaz}`: Añade una IP a una interfaz.
	4. `ip route add {IP de origen} via {IP de destino}`: Crea una ruta entre 2 IPs.
	5. `ip add/dev del ...`: Elimina un enlace de IP.

# Parámetros de los archivos de la configuración de la red

Estos archivos se encuentran siempre en la dirección `/etc/systemd/network/*.network`, y sus parámetros son los siguientes:

1. **Con `[Match]`**.
	1. `Name=`: Nombre de la configuración, que normalmente coincide parcialmente con el nombre del archivo. Dicho campo se puede ver con el comando \*.
	2. `MACAddress=`: Dirección de la MAC.
	3. `Type=`: Tipo de interfaz.
2. **Con `[Network]`**.
	1. `DHCP=`: Establece si se va a usar DHCP, también se puede especifica si es solo para IPv4 o IPv6 indicándolo a continuación.
	2. `Address=`: Dirección IP estática.
	3. `Gateway=`: Puerta de enlace predeterminada.
	4. `DNS=`: Servidores DNS, es posible especificar varios si se separan las IPs mediante espacios.
	5. Hay más parámetros, pero nunca se suelen usar.
3. **Con `[Address]`**.
	1. `Address=`: Dirección estática adicional.
	2. `Broadcast=`: Dirección _broadcast_.
4. **Con `[Route]`**.
	1. `Gateway=`: Puerta de enlace para una IP específica.
	2. `Destination=`: Destino estático para una IP.

Normalmente, se crea un archivo de este tipo por cada interfaz conectada, contando siempre con `loopback`.
