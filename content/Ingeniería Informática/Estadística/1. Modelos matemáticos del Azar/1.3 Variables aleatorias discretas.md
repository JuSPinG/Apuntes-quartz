# Definición

Supongamos que vamos a lanzar una moneda 3 veces, y luego vamos a transmitir los resultados por un medio con ruido:

$$\Omega=\{\{\text{cara}, \text{cara}, \text{cara}\}, \{\text{cara}, \text{cara}, \text{cruz}\}, \{\text{cara}, \text{cruz}, \text{cara}\}, \{\text{cruz}, \text{cara}, \text{cara}\}, \{\text{cara}, \text{cruz}, \text{cruz}\}, \{\text{cruz}, \text{cara}, \text{cruz}\}, \{\text{cruz}, \text{cruz}, \text{cara}\}, \{\text{cruz}, \text{cruz}, \text{cruz}\}\}$$

Desde aquí, podemos asociar cada uno de los resultados a un fenómeno, como que un dato se ha transmitido mal. Dada la circunstancia, deja de tener tanto sentido la probabilidad de "cara" o "cruz". Podemos asignar que "cara" corresponde con el error, y podemos medir cuántos errores hay:

![[Ejemplo variables aleatorias.png]]

Aparece una distribución de los errores curiosa. De especifica que es más probable que se haya cometido solo un error que 0 o 3 (juntos). Y es igual de probable que se haya cometido un error, a que se hayan cometido 2.

> [!note] Sobre las variables aleatorias.
> Una variable aleatoria $X$ definida sobre un espacio de probabilidad $(\Omega, P)$ es una función $X:\Omega \mapsto P$.

El conjunto de valores que puede tomar $X$ se corresponde con la imagen de $\Omega$. Por ejemplo, si se lanzan 2 dados, y $X$ es la variable que mide el "mayor de los número obtenido al lanzar los dados":

$$X(\Omega)=\{1, 2, 3, 4, 5, 6\}$$

Si el conjunto $\Omega$ es infinito, entonces, $X$ no es considerada una variable discreta.

Hay 2 formas de definir una variable aleatoria. La primera de ellas consiste en la evaluación exhaustiva de lo que devuelva $X(\omega), \omega \in \Omega$. Volviendo al ejemplo de cara o cruz:

$$X(XXX)=0; X(XXC)=1;X(XCX)=1;...X(CCC)=3$$

Esto devuelve una distribución gaussiana.

Este método de la fuerza bruta no es conveniente cuando $\Omega$ posee muchos elementos. Por otro lado, se puede definir con precisión la variable aleatoria, esto se puede hacer mediante palabras:

$$X=\text{"Número de errores al transmitir 3 dígitos binarios"}$$

# Formalismos

Se usa la representación $\{X=x\}$ para representar todo el conjunto de elementos $\omega$ que cumplen $X(\omega)=x$:

$$\{X=x\}=\{\omega\mid X(\omega)=x\}=X^{-1}(x)$$

Es decir:

$$\{X=3\}=\{CCC\}$$

Una variable aleatoria se puede descomponer como variable aleatoria de otras variables indicadoras. Por ejemplo, si $A$ es un suceso, su variable indicadora se representa como $I_A$, y toma el valor 1 si $A ocurre, y 0 si $A$ no ocurre:

$$I_A(\omega)=\begin{cases*}
1 \text{ si}\;\omega \in A \\
0 \text{ si}\;\omega \notin  A \\
\end{cases*}$$
