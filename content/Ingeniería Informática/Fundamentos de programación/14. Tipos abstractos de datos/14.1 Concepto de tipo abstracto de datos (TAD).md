En la programación tradicional, si, por ejemplo, hace falta representar los meses de año, se pueden usar números del 1 al 12 o iniciales como "ENE", "FEB" y todas las que siguen.

```c
/*-- Método 1 --*/
typedef int T_Mes;

/*-- Método 2 --*/
typedef char T_Mes[4]; /* 3 caracteres más uno del final */
```

Y de forma más moderna, se puede usar un enumerado:

```c
typedef enum T_Mes {Enero, Febrero, ..., Diciembre};
T_Mes mes;

printf("%d", int(mes) + 1);
```

Aquí, se identifican los tipos de datos de forma completamente abstracta. Llegando, así, a un tipo abstracto de datos (TAD)
