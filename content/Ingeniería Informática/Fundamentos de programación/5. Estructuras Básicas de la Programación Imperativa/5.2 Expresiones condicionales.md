Estas se encargan de evaluar si una comparación es cierta o no. Se usan operadores de comparación en operaciones aritméticas para poder construir "expresiones condicionales". Y, claramente, deben de ser del mismo tipo, no se puede comparar un número con una letra.

Los operadores posibles son los siguientes:

- De comparación:
	- `>`.
	- `>=`.
	- `<`.
	- `<=`.
	- `==`.
	- `!=`.
- Expresiones lógicas:
	- `&&`.
	- `||`.
	- `!`.

El operador `&&` posee una curiosidad, si la primera parte de la operación compuesta es falsa, entonces no se evalúa el resto, así, el programa va más rápido. A esto se le llama "evaluar en cortocircuito".

Al juntar tantos operadores y valores, se genera una "expresión aritmética":

```c
(largo < 3) && (ancho < 9) && (largo*ancho < 25)
(!letra == 'Q') || (letra == 'Z')
```

El orden, si no viene especificado por un paréntesis (aunque son de obligatorio uso), es el siguiente:

1. Operadores Unitarios: !, +, -.
2. Operadores Multiplicativos: *, /, %.
3. Operadores Aditivos: +, -.
4. Operadores Comparativos: >, >=, <, <=.
5. Operadores de Igualdad: \==, !=.
6. Operadores Conjuntivos: &&.
7. Operadores Disyuntivos: ||.
