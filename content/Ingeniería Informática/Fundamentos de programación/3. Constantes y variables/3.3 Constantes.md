# 3.3.2 Declaración de constantes con nombre

Enlace: [[Fundamentos de programación.pdf#page=67&selection=6,0,18,6|Fundamentos de programación, página 67]].

Una constante se declara de la siguiente manera:

$$\texttt{<Constante> ::= const <Tipo de variable> <Nombre> = <Valor>;}$$

He aquí un ejemplo:

```c
const char Texto[] = "Hola, muy buenas";
```
