Los elementos de la programación estructurada (secuencia, selección, e iteración) corresponden cada uno a los esquemas dados hasta ahora:

- `struct` → Secuencia: Colección de elementos diferentes, combinados en un orden fijo.
- `union` → Selección: Selección de un elemento entre varios posibles, de tipos diferentes.
- `vector` → Iteración: Colección de elementos del mismo tipo.

Supongamos un esquema resumen:

```c
/*******************
  ESQUEMA DE DATOS
********************/
  
/*-- Esquema de tupla --*/
typedef struct TipoTupla {
  char uno, dos, tres;
};
TipoTupla agregado;

/*-- Esquema de unión --*/
typedef union TipoUnion {
  int alfa;
  float beta;
}
TipoUnion variante;
bool numeroEntero;

/*-- Esquema de formación --*/
typedef int TipoFormacion[10];
TipoFormacion vector;

/**********************
  ESQUEMA DE ACCIONES
***********************/

/*-- Secuencia para imprimir los campos de una tupla --*/
printf("%c", agregado.uno);
printf("%c", agregado.dos);
printf("%c", agregado.tres);

/*-- Selección para imprimir las variantes de una union --*/
if (numeroEntero) {
  printf("%d", variante.alfa);
} else {
  printf("%f", variante.beta);
}

/*-- Iteración para imprimir un vector --*/
for (int i = 0; i < 10; i++) {
  printf("%d", vector[k])
}
```
