Una expresión aritmética representa un cálculo a realizar con valores numéricos. Se conforma por operandos y operadores.

Cuando se realiza un cálculo, es importante saber si el valor obtenido es un entero o un real, $33.7/5$, por ejemplo. En función del tipo que se establezca, dará un resultado u otro. Por ello, muchas veces se necesita pasar los datos de un tipo a otro, esto se hace usando la función `float(X)` e `int(X)` según convenga. Como resultado, ya se puede definir si la división debe de devolver un entero o un real:

```c++
33.7 / float(5) = 6.74 // float
int(33.7) / 5 = 6 // int
```

Aunque de forma automática, C/C++, cambia los datos para obtener el mayor rango y precisión posible, de todas formas, es importante tenerlo.
