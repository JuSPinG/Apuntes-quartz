Normalmente, los módulos (E/S y memoria) pueden interrumpir el procesamiento de la CPU. El objetivo de dichas interrupciones radica en un mayor rendimiento.

Debido a la lentitud de los módulos, puede suceder que, cuando una CPU ordena a una impresora que imprima un papel, sucede que la CPU se tiene que quedar esperando mientras la impresora realiza sus tareas; esta es una mala gestión de la CPU.

Supóngase 2 programas, uno de ellos transfiere datos a un dispositivo E/S, el otro, requiere de un gran cálculo numérico. Inicia la CPU y envía los datos requeridos al módulo E/S, y se pone a hacer el cálculo numérico. Al cabo de un rato, el módulo E/S necesita datos de nuevo. Entonces, envía una "_petición de interrupción_", y la CPU vuelve a hacer caso al módulo E/S. Es necesaria la existencia de esta instrucción.

![[Ejemplo diagrama instrucción de interrupción.png]]

Todos los sistemas operativos poseen un manejo de interrupciones.

![[Ejemplo diagrama con interrupción.png]]

Como es de esperar, todo este proceso extra requiere de un tiempo de procesado extra, pero es más tiempo el que se pierde mientras el módulo E/S se queda esperando. De todas formas, hay interrupciones que se pueden desactivar, lo que no desvía el flujo de ejecución cuando aparecen; también se pueden volver a activar.
